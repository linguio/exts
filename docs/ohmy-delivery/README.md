# 开发交付宪章

这里统一维护 exts 的本地工作项。任务事实以对应 Issue 为准。

- [想法收件箱](inbox.md)用于临时想法。
- [未关闭 Issue](issues/)包含排队、实施、待验收和待提交的工作项。搜索元数据即可查看当前项和队列。
- [历史记录](history/)按建档年份保存已完成和已取消的 Issue，同一文件名贯穿建档与归档。
- [Issue 模板](../../.agents/skills/ohmy-delivery/assets/template-issue.md)及[英文字典](../../.agents/skills/ohmy-delivery/assets/issue-dictionaries.json)供建档和读取共用。

一条活动 Issue 负责一个可独立验收和回滚的结果。验收通过后留在未关闭目录，最终文档提交时写入完成状态并归档。取消时记录原因并归档。每条 Issue 的交付记录保存实际交付、验证、验收和提交消息。开发规范见[仓库规则](../../AGENTS.md)。
