# 替换扩展轻量圆角矢量 Logo

已完成。

## 目标与范围

### 背景与目标

扩展展示 exts.svg 将 1024px Apple 正式 PNG 内嵌进 SVG，大小 537805 字节。用户希望使用接近 GitHub SVG（822 字节）的轻量纯矢量资源，已认可原始主体加普通圆角的预览。

### 范围与排除项

- 将 apps/extension/src/assets/brand/exts.svg 替换为已确认的 1274 字节圆角预览：保留原始路径与变换，1254 画布，底板圆角半径 280。
- 原有 Studio、Newtab 引用、主题行为与资源路径保持不变；核对生产构建与 ZIP 的真实体积。
- 本次为用户指定的扩展展示替换，例外于原 Apple 位图封装路线；不宣称普通圆角与 Apple 轮廓一致。
- 不修改品牌唯一源稿、macOS 工程、各尺寸 PNG、网站图标、权限、依赖或目录结构；不上传云端，不提交或推送。
