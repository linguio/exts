# 简化表格操作与筛选并减少 Studio 刷新提示

## 当前阶段

用户确认全部验收通过，批准提交并推送。

## 目标与范围

- Daily 的 Actions 列只有 Edit，直接显示带 Tooltip 和无障碍名称的 SquarePen 图标按钮，点击打开现有编辑 Sheet。在共用表格行操作组件实现，单项有明确图标时直出，含义不清楚时用短文字。当前不扩建多操作配置。
- 共用 DataTable 工具栏根据业务已有的字段、控件类型和选项渲染筛选项。关联列的 Label 取文本表头，使用中等字重且不加冒号，与控件同行，筛选区一行四个位置。Query、Reset、Columns 作为一组，放到未满四项的最后一行最右侧；刚好排满时另起一行靠右。窄屏只在筛选区内横向滚动，操作组在对应行的可见右侧保持可用。
- 移除 Newtab 的 Studio 在整页刷新时的账号初始化 Spinner。保留侧栏与顶栏，等账号结果确定后显示对应页面。账号授权、错误状态以及 Daily、Dictionaries 自己的数据加载反馈维持原流程。
- Dictionaries 菜单换用 Lucide BookA 图标。
- 复用既有 shadcn 组件和共用逻辑。范围不包含修改基础组件、改变查询契约或调整 Dictionaries 独立搜索。

## 验收标准

- Daily 行末可直接点击铅笔图标打开原编辑 Sheet，表格横向滚动时操作列保持原有固定行为。
- 按配置看到同行 Label 与筛选控件。0～3 项时操作组在第 1 行最右侧，4～7 项在第 2 行最右侧，8～11 项在第 3 行最右侧。操作组三个入口整体移动，查询、重置、列显隐行为一致。
- 缩窄窗口并横向滚动筛选区时，操作组仍位于对应行的可见右侧，可以直接使用。
- 整页刷新且恢复到 Studio 时，账号读取过程保留外壳、不显示账号 Spinner。账号返回后显示可访问内容，业务数据加载仍有独立反馈。
