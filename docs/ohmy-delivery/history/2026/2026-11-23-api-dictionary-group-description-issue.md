## 验收标准

- 生产库三个既有分组按 key 对应各自的英文用途说明。
- 启动新版 API，Chrome 或 Edge 加载根 `dist/build/chrome-mv3` 后，进入 Studio → Management → Dictionaries。
- 输入名称或 key，停输后结果自动过滤，清除恢复三组。无匹配、查询失败都显示 Empty，加载在相应数据区居中。超过 20 组时左侧页脚可用页码切换，省略号可跳页。
- 切换 Status、Scope、Type 时显示对应描述。Label、Value、Order 始终居中等宽，右侧全部显示且无分页。缩窄窗口、滚动有足够数据的分组时，检查页面边界和固定表头。
