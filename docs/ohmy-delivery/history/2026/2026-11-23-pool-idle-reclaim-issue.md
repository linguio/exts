- 同一存活的本地 Python 进程使用应用的池化数据库地址，分别建立两组池。探针通过共用请求路径借用连接并执行只读 `SELECT 1`，没有读取业务数据。每组先执行五次热请求，再观察 90 秒及 130 秒的池状态，130 秒时发出首条探针请求。

| --- | --- | ---: | ---: | --- | ---: |
| 60 秒 | 0.03 / 269.40 ms | 1 | 0 | 2541.55 / 2784.67 ms | 241.81 ms |
| 300 秒 | 0.02 / 233.76 ms | 1 | 1 | 0.03 / 232.83 ms | 228.80 ms |

- 60 秒组在首条空闲请求时新建了连接，300 秒组复用了原连接。基线 90 秒未回收到零，实际回收取决于池的检查周期。保留 `max_idle=300`、`min_size=0` 及其余配置。
