# 接入字典组和字典项维护

## 当前阶段

后续待办。本轮仅记录已讨论的交互。

## 目标与范围

接入新增组、编辑组、新增项和编辑项，复用各自的 Sheet 表单。新增组时必须明确选择一个归属。已有 Namespace 从可搜索列表中选择，`+ Create namespace…` 固定第一项且始终可见。没有匹配时，在该入口下显示 `No matching namespaces`。

创建 Namespace 时，在当前 Sheet 内填写显示名和 key，确认后回到新增组表单并自动选中新归属。最终保存时在同一事务写入新归属与组，取消或失败时不留空归属。归属 key 标准化后校验唯一，遇到已有 key 时保留组表单输入并提示选已有归属。

新增或编辑项时显示当前归属和组名。日常编辑以显示名、描述和顺序为主，已被业务引用的 key 或 value 的变更规则留待实施前确定。权限及写入契约在启动此项时确认。删除和批量维护另行讨论。

## 验收标准

- 搜索有无匹配时，创建归属入口始终位于首项。
- 选择已有归属只新增组。选择新归属时，保存后同时出现归属和组。
- 创建冲突或提交失败时保留输入，取消时不写入。
- 修改保存后更新对应分组或字典项。
