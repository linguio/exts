# 想法收件箱

- 后续 X Download／Helper 接入：Extension 提交任务，Helper 独立下载与整合，成功后只通知一次；允许丢失，不确认、不重试、不补发、不恢复。关闭总开关屏蔽网页入口并停止通信，不终止任务。未来使用 x-download 目录；不纳入本次下载整合或设置两个 Issue。

- Issue 元数据定时同步：从公开仓库指定分支定时读取本地 Issue 文档的已推送版本，同步状态等元数据供只读列表和统计使用，正文链接到源文件。

- 账号角色与权限设计：后续统一设计普通账号与管理权限，明确 Studio 管理菜单、页面访问和 API 操作的授权规则。优先覆盖字典等全局共享配置的写入权限，具体角色、授权方式和开放范围待讨论。

- 共用 Web 组件逐项迁入 `@linguio/exts-ui/plus/*`：以现有 `@linguio/exts-ui/plus/toast` 为例。所有已迁入的 shadcn 基础组件源码保持只读。需要扩展基础组件的样式或行为时，在包的 `plus/*` 新增或复用对应的 Exts 共用组合，页面统一调用。Table、Sheet、Tooltip 的历史适配暂时保留，等有实际增强或复用需求时再逐项迁移、验收。候选包括 Sheet 的项目样式和焦点、Tooltip 的通用触发规则、DataTable 的展示与通用流程。LoadingRegion、StatusIcon 在出现跨应用复用需求时再评估。业务列、账号、接口和 Chrome 消息留在应用。Toast 的文案、触发时机、设置读取和宿主容器选择也由应用负责。
