# 官网视觉规范

状态：已批准，2026-10-11 用户确认尺寸方案；本地实施完成，实际页面效果待用户验收。适用于 apps/website 的首页与 Changelog；本文件维护长期规则，交付进度见[对应 Issue](./changes/issues/2026-10-11-website-layout-system-issue.md)。

## 主题与组件

- 固定浅色、黑白风格，不增加深色模式。沿用现有系统字体栈。
- 颜色沿用 shadcn 语义 token，定义在 apps/website/src/app/styles.css；业务组件引用语义颜色，不各自新增硬编码颜色。
- 图标入口和年份链接使用现有 shadcn Button，平台标签使用 Badge，通用图标使用现有 Lucide；品牌资源遵循 [Logo 规范](./exts-logo.md)。
- 仅将两页实际复用的排版与布局值提取为共享规则；不建设额外主题框架，不增加依赖。

## 颜色层级

| 用途 | 语义 token | 当前值或用法 |
| --- | --- | --- |
| 页面背景 | background | #ffffff |
| 标题、年份、正文 | foreground | #191919；正文用普通字重区分，不靠过浅颜色 |
| 下载按钮、平台标签 | primary / primary-foreground | #191919 / #ffffff |
| 月日、版权等辅助文字 | muted-foreground | #737373 |
| 入口悬停、当前页面 | accent / accent-foreground | #f2f2f2 / #191919 |
| 页头分割线、时间线 | border | #e8e8e8 |
| 键盘焦点 | ring | #737373，沿用组件焦点反馈 |

平台标签仅以 Website、Chrome、macOS 文字分类，统一黑底白字，不使用平台彩色。最新记录节点为 primary，历史节点使用 border 与 background。

同一事件涉及多个平台时，共用日期和事件标题，正文按平台分组：每组标签放在该组无序列表上方，组间距 24px，默认全部展开。不把多个平台标签堆在同一列表上方，也不逐条重复标签。单平台沿用同一结构。

| Changelog 页面标题 | 手机 28px，桌面 32px | 1.2 | 600 |
| 日志事件标题 | 20px | 32px | 600 |

年份使用 foreground，月日使用 muted-foreground；事件标题仍为主要视觉重点。日志不显示版本号、副标题或重复的新增／修复分类。日期保持完整 dateTime 语义，显示月日。

## 宽度与间距

- 共用外层最大宽度 1152px，左右内边距手机 24px、640px 起 40px、1024px 起 48px；页头与正文外层使用同一规则。
- Changelog 阅读区域最大宽度 720px；首页保留原有桌面两列和手机上下布局，不改变标语、下载按钮与 Logo 关系。
- 使用现有 4px 间距步进；常用间距为 8、12、16、24、32、48、64px，保留标签之间 6px 的紧凑间距。
- 日志标题到标签 8px，标签到正文 16px，列表条目间距 8px；日志记录间距桌面 64px、手机 48px。
- 页面标题到时间线桌面 32px、手机 24px；正文距页头额外留白桌面 48px、手机 32px。
- 标签圆角 6px、左右内边距 8px、上下内边距 2px，保持显示标签的轻量尺寸；导航点击区域 40×40px，保留现有组件反馈。
- 年份分组沿用现有左侧年份、月日、节点与正文列；桌面年份在所属年份组内吸顶，距离固定页头下沿 24px，随年份组结束离开；手机年份放在组上方，不吸顶。

## 固定共享页头与页脚

- 两页继续复用 SiteHeader 与 SiteFooter，尺寸与行为统一。
- 页头固定于视口顶部：桌面高度 56px、手机 52px；品牌入口使用现有 28px Logo 与 20px Exts 文字，间距 10px。背景使用 background 的 85% 不透明度，背景模糊 12px，仅底部一条 1px border 分割线，不加阴影。
- 模糊不可用时使用实色 background 降级；保持文字、图标与正文的可读性。
- 页脚固定于视口底部：基础高度 48px，使用实色 background，无模糊、分割线或阴影；保留 © 2026 Lin Gui。
- 支持设备安全区；安全区计入固定区域占用与正文预留，不让内容或操作落入设备遮挡区。
- 正文预留完整页头和页脚高度；页面底部再留 24px，确保最后一条完整可见。短页面保持主体在可用区域内布局，小高度视口允许正常页面滚动。
- 固定区域层级高于正文；不创建嵌套滚动容器，页面仍由浏览器正常滚动。

## 定位与交互

- 年份链接定位到该年第一条；锚点顶部间距为实际页头占用高度加 24px，包含安全区，避免标题被遮挡。
- 年份颜色加深、字重 500，保留 ghost 按钮的悬停、按下与焦点反馈；不增加自动滚动加载或动画。
- 首页和日志页的导航位置一致，图标不使用常驻选中背景，仅悬停时使用 accent 反馈，保留键盘焦点与当前页面的 aria-current 语义。

## 验证与维护

- 必要自动化只检查类型、构建和相关逻辑及产物；视觉、布局、滚动、焦点与点击由用户在 Chrome 或 Edge 验收。
- 规则改变时更新本文件，README、应用约束和 Issue 通过链接引用，不复制整份规则。
- 新页面复用实际需要的规则；超出本规范或当前 Issue 范围的设计变更需另行确认。
