# 桌面应用

Exts 桌面端是 macOS 原生应用，当前包含设备媒体模块；Photos 是该功能的介绍名称，不是新增的独立应用或工程。

## 功能

- [Photos 设备媒体](./ohmy-photos.md)：连接 iPhone、浏览设备媒体、选择并下载到本机。
