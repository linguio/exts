## 背景

首页右侧目前是静态品牌 Logo。用户希望换成与产品相似的界面示意，展示已有 Tabs 与 desktop Media 功能，沿用克制的黑白视觉，使用重叠自动切换。不是完整截图，也不新增产品功能。

## 目标

保留左侧标语和下载按钮，用统一风格的两张模块卡片展示当前产品能力；自动轮换并允许点击后方卡片立即置前。

## 范围

- 仅替换首页右侧大 Logo 展示区域；页头品牌 Logo、左侧文案、实际下载链接、共享页头页脚与 Changelog 功能保持原有行为。
- 模块仍名为 Tabs；只展示一个新标签页场景，不拆成书签、Dock、标签组等多个场景。
- Tabs 使用现有 SVG 书签图标网格，图标有细边框与小圆角，不显示文件夹、书签名称或“我的新标签页”标题。
- Tabs 底部 Dock 展示 ChatGPT、GitHub、Gmail、Components、DevTools；每个图标独立细边框，分隔线清楚，工具 SVG 完整可见，不显示文字名称。
- Media 根据现有按月份浏览 iPhone 媒体、选择与下载功能制作简化示意；仅图片和视频两种占位 SVG，不使用花朵、山等占位图，不引入真实个人照片。
- Media 工具栏左侧月份、右侧“已选 2”和纯文字“下载”，无“全选”，下载无黑色底或图标。此处是示意内容，不提供真实下载操作。
- 两张卡片共用窗口外框、顶部栏、边框、圆角和控件尺寸规则；黑白白底、轻边框、无厚重阴影，沿用最终批准的略微倾斜错位叠放效果。
- 默认 Tabs 在前，每 3 秒自动轮换一次；无底部切换按钮或额外模块标题。点击露出的后方卡片立即开始置前过渡，与自动切换使用相同动画，不等待轮播周期。
- 悬停或键盘焦点进入展示区时暂停，离开后重新计算轮播周期；键盘 Enter/Space 可切换卡片，保留焦点反馈。页面隐藏时暂停，离开页面清理定时器，减少动态效果偏好下不自动轮播。
- 卡片池最多展示三张，自动移出首张并由下一张补位，循环结束后第一张在末尾回归；点击仅临时调整可见窗口，不改变池顺序。正式数据只有 Tabs、Photos，移除临时示例卡。
- 卡片顶部仅保留 Tabs、Photos 功能名，取消装饰圆点；Photos 为官网展示名称，实际 desktop Media 模块不改。
- 使用现有 React、CSS 与本地 SVG 实现独立首页展示模块，不新增依赖；更新必要的官网说明及视觉规范引用，规范与实现保持一致。

## 排除项

- 不修改 extension 或 desktop 实际 UI、功能、模块名称，不把示意工具栏变成业务入口。
- 不增加未来模块、真实截图采集、个人媒体、Three.js、AI 视频或图片生成。
- 不调整左侧下载按钮、产品版本、依赖、品牌源稿或部署流程，不自动提交、推送或部署。
- 不新增截图、像素、布局、焦点或指针自动化测试；浏览器视觉与交互由用户验收。

- 首页左右主体关系保持，右侧两张示意卡片与批准预览一致，两端使用统一风格。
