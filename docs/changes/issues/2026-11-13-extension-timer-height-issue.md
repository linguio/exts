# 调整时间卡片高度与数字比例

## 元信息
- 项目：extension
- 状态：已完成
- 批准依据：用户澄清调整对象为内部数字翻页牌，并明确要求外框恢复文件夹固定高度；数字比例2.8保留。
- 规模：小型样式调整

## 背景与目标
保持文件夹固定尺寸与数字比例2.8；用户通过截图明确顶部、操作行与数字牌之间、底部三处可见留白要与文件夹内边距一致，按实际尺寸计算内部翻页牌高度。

## 范围
TimerCard宽高保持文件夹基准（默认178px）；数字scaleY为2.8。文件夹内边距实际16px，以操作行16px可见图标为界，三处留白各16px，数字牌默认高112px（178−2边框−3×16留白−16图标）。保留32px官方按钮点击区域，采用顶部8px、行间8px、底部16px布局补偿按钮内部留白；数字牌填满剩余高度，取消固定宽高比与额外垂直居中。同步现行规范。

用户追加批准：首页卡片上下顺序互换，日历在上、时间卡片在下，保持各自尺寸；两卡片间距由24px改为32px，与左侧两排文件夹外框之间的8px名称前距＋16px名称高度＋8px行距一致。

## 排除项
不调整Slider官方样式、日历内部或其他文件夹，不改按钮点击区域、计时/声音逻辑、版本号，不提交Git。Slider轨道和拇指仍按官方大小居中，不把其较窄边缘与操作行整体可见范围混为一谈。
