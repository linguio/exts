# 将 API 根地址跳转到文档

## 元信息

- 工作项：2026-11-01-api-root-docs-redirect
- 状态：已完成
- 当前阶段：用户明确要求先本地提交完结，代码已提交，完成状态随文档提交归档；未推送或部署，浏览器及线上验收未执行。

## 背景

改造前 apps/api 提供 /docs 文档与受令牌保护的 /hello，未配置根路径 /。直接访问 https://api.exts.linguio.dev/ 会因未匹配路由返回 404，容易被误解为服务故障。

## 目标

访问 API 根地址时自动进入现有 Scalar 文档，移除临时 /hello 数据库探针；保留数据库连接配置，暂不新增正式业务接口或用户认证。

## 范围

- 在 FastAPI 中添加 GET /，以 307 临时重定向指向相对路径 /docs，本地与生产复用。
- 根路由无需令牌，不访问数据库，不出现在 OpenAPI 业务接口列表中。
- 在现有 API 测试中验证重定向状态与 Location。
- 移除 /hello 路由、专属模型与个人令牌校验，以及已失效的探针测试和真实联通验证脚本；验证旧路由返回 404，文档不再宣称提供该接口。
- 在 API README 中说明根地址入口，并补充实际交付记录。

## 排除项

- 不修改数据库连接、表结构、数据、Neon 配置或环境变量。
- 不新增登录或其他正式业务接口，不修改 Scalar 样式、官网入口、项目版本或第三方依赖。
- 保留私有环境文件、环境变量模板与数据库连接依赖，不执行数据库变更，不修改 Vercel 环境变量。
- 不调整 Vercel 项目、域名、分支规则或部署工作流。
- 不自动提交、推送或部署。

## 验收标准

- 本地运行 pnpm api:dev，访问根地址后浏览器自动进入同一服务的 /docs 并显示现有文档。
- 不跟随跳转请求 GET / 时返回 307，Location 为 /docs。
- 根地址与文档均无需令牌，访问根地址不会连接数据库；OpenAPI 不增加根路由条目。
- /hello 返回 404，OpenAPI 不再包含该接口或其鉴权说明；不新增替代业务接口，不改动数据库或人为破坏配置。
- 本地验证不等于生产已部署；获批部署后由用户访问正式根地址确认跳转与文档加载。
- 浏览器交互由用户验收，代理不执行视觉或交互自动化测试。
