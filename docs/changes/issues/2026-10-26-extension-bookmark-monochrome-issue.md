## 背景
Newtab 书签目前混用 original、adaptive 与 neutral 配色。UI 图标存在灰阶和白色覆盖区域，Grok 与 Exts 保留固定底色，导致同一组入口的配色规则不一致。

## 目标
书签网格与 Dock 的图标统一随主题反色：普通书签透明背景，浅色主题黑色、深色主题白色；Exts 参考 GitHub 书签的明暗切换，保留完整外形及内部黑白对比。

## 范围
- 合并 Newtab 书签图标的三种配色策略，复用现有明暗主题转换，不新增主题系统。
- UI 图标去除灰阶和渐变；白色覆盖形成的图案孔洞转换为真正透明区域，避免整体滤镜把图案压成实心块。
- Grok 去除背景，仅保留既有主体路径。Exts 书签继续使用已有正式图标完整资源，浅色黑色外底与白色主体、深色白色外底与黑色主体；深色反色参考 GitHub 书签，不抹掉内部对比或移除外框。
- Exts 的反色仅发生在 Newtab 书签渲染层；品牌唯一源稿、书签正式资源、desktop、website 与三端应用图标不更改。
- 保留现有图标几何、构图及显示大小，不套用 V3 重绘或统一 1024 坐标要求；同步 Newtab 配置、必要调用方、现有配置测试及当前 UI 规范。

## 排除项
- 不改变书签名称、网址、顺序、文件夹、模糊、滚动或 Dock 交互。
- 不重绘品牌图案，不新增依赖、公共主题框架或浏览器权限。
- 不执行浏览器视觉、布局或交互验收，不提交、推送或发布。

## 用户验收步骤
1. 在 Chrome 或 Edge 扩展管理页加载或重新加载根 `dist/build/chrome-mv3`，打开新标签页；本轮正式构建已更新，不加载旧稳定开发目录。
2. 在 Settings 中切换 Light 和 Dark：以 GitHub 书签的主题反色为参照，检查普通书签分别为黑色和白色；Exts 浅色为黑色外底、白色主体，深色为白色外底、黑色主体，完整外形没有丢失。解除 UI 文件夹模糊并滚动查看七个图标，重点检查 Iconfont 细节与 shadcn.io 中心孔洞没有变实心。
