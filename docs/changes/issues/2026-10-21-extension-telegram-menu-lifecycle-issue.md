## 背景与目标
Telegram 页面存在重载报错和菜单主题、hover 问题。用户进一步要求精简下载入口和反馈，移除现有 Popup，后续统一下载界面另行设计；当前只在下载完成时提示。共用层仅提供官方样式组件，下载状态和提示触发仍由 TG 模块负责。

## 范围
- 最新确认：文件名生成规则保持原样；完成 Toast 标题“下载完成”，附实际保存文件名；取消或失败只清理资源、恢复入口，不弹提示。
- 用户单独批准删除设置 Tooltip 中的“Turning this off blocks new downloads immediately; downloads already started continue.”；仅保留功能简介，不改变开关行为。此文案修改先实施。
- 用户最新单独批准：将另存为 startIn 固定为 desktop，作为系统桌面的建议初始位置；保留原 picker id，不增加目录授权或自动保存流程，不承诺锁定最终路径。此项先实施，其余新增范围仍待核对。
- 消息发送捕获同步异常和异步拒绝；上下文失效后停止发送、停止进度定时器并关闭页面入口，清理过程不再调用消息接口。
- 修复共用主题 Token 从 :root 转换到 Shadow DOM :host 时的带属性选择器。
- 下载操作组合现有官方 DropdownMenuItem 和 Button；使用 ghost 的 hover 与用户要求的手形指针，保留禁用及菜单语义。
- 按钮显示下载图标加“下载资源”，宽度 fit-content；菜单容器不以固定最小宽度撑开按钮。
- 删除当前 Popup 入口、展示组件和构建配置中的专用引用，后续统一下载界面不在本次实现。
- 删除 src/modules/downloads 及其后台注册、历史持久化、消息和专用测试；删除 TG 中仅为该记录层服务的任务快照、进度上报与后台适配。保留真实下载行为测试，不把这些业务移入共用 UI，也不迁移或清空既有存储数据。
- 删除手写提示框，采用 shadcn 官方 Toast 组件；只在 writable.close() 成功后显示“下载完成”。不弹开始、进度、失败或取消提示。多个完成 Toast 使用官方组件自带的堆叠/折叠能力，不自行实现。
- 共用组件放在扩展 shared/ui，仅负责样式与基础展示交互；TG 模块持有文件名、任务状态和提示触发逻辑，不抽全局通知管理层或共用下载业务。
- src/modules/telegram-download 改名为 src/modules/tg-download，调整活动代码、入口、测试和文档引用；不顺带修改既有配置存储键或事件协议，避免丢失设置。
- 参考 Newtab 按职责组织模块内部目录，区分业务组件、设置视图、下载处理、页面接入，不平铺全部文件，不新建服务层、注册器或空目录。
- 更新组件来源、固定版本及必要差异，以及扩展提示规范；仅引入所需的官方组件依赖，不升级其他依赖。

## 模块内部目录方案（已实施）
```text
tg-download/
├─ components/download-menu/   # 下载菜单的业务组件与样式
├─ views/settings/            # 仅 TG 开关视图，由 Newtab 设置面板组合展示
├─ download-core/             # 保存流程、分段写入、文件名
├─ page/                      # 媒体识别、页面注册、配置与主题桥接
└─ settings.ts                # 业务配置键与默认值
```
共用官方 Toast 位于 shared/ui，不包含 TG 状态、提示文案或下载逻辑。上述目录只容纳现有或本次必需实现；设置键及仍需使用的配置/主题事件保持兼容，废弃的下载记录消息直接移除。移除记录层后，不为修复旧报错保留已失去用途的消息发送与进度定时器。

## 用户验收步骤
1. Chrome/Edge 加载根 dist/build/chrome-mv3/；重新加载扩展后刷新 Telegram Web，确保页面运行本次脚本。
2. 工具栏不再打开 Downloads Popup；Newtab 分别选择 Light、Dark、System，在 Telegram 媒体查看器右键，检查下载菜单和完成提示跟随主题。
3. 下载项显示图标加“下载资源”，宽度随内容，指向时有手形指针和 hover；点击打开另存为。取消、开始、进行中和失败不弹 Toast，只有文件保存完成弹“下载完成”。
4. 保持 Telegram 页面打开，重新加载扩展，触发旧页面菜单或进度事件，检查不再出现未捕获 Extension context invalidated；旧入口应停用，刷新 Telegram 后可恢复使用。
5. 连续完成多个图片/视频下载，检查每次成功均有完成提示，多个提示由官方组件折叠堆放；确认保存文件可用。活动源码模块名为 tg-download，既有开关配置保留。

## 验收标准
重载后无未捕获上下文错误，刷新页面后恢复。下载项图标加“下载资源”、宽度随内容并有主题/hover/手形反馈；取消与失败不报成功，只有文件关闭成功后出现官方完成 Toast，多个提示使用官方折叠能力。Popup 移除，模块更名 tg-download；共用层不包含下载业务。
