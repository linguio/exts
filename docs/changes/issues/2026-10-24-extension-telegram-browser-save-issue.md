## 背景与目标
保留现有另存为取流与写盘方案，将常用快速下载放在主按钮，把另存为与重新选择收进横向三点菜单。此前改用浏览器 downloads API 的方案已取消。

## 范围与设计
- 按用户最终提供的 ButtonGroupDropdown 组合：下载资源与三点处于同一个 ButtonGroup，均用 outline Button，不额外插入 ButtonGroupSeparator；保留 Radix asChild 触发器，不加子组、分隔线覆盖、宽度测量或间距变量。
- 三点下拉菜单沿用共用组件默认宽度，不测量或手动指定与按钮组等宽。
- 图片或视频预览关闭时，下载按钮组及三点菜单一并收起，清除当前媒体引用；不影响已开始的下载。只监听当前 TG 预览层，不轮询或全页扫描。
- 使用 shadcn/ui 官方 Button Group，与现有官方 Button、DropdownMenu 组合为分体按钮；官方 Popover 仅负责右键面板定位，避免嵌套菜单项中的交互控件。
- 左侧主按钮为下载图标加「下载资源」；右侧横向三点菜单依次为「文件另存为」「选择文件夹」，默认收起次要操作。
- 快速下载沿用现有目录句柄与流式写入，保存到已授权并记住的文件夹；首次无目录时先选择并授权，随后继续本次保存。权限失效仍需恢复授权，同名文件自动编号。
- 另存为使用既有 showSaveFilePicker 和 Range 分段取流、逐块写入，每次选择本次文件名和位置，不改变快速下载目录。
- 重新选择只更新快速下载位置，不触发本次下载；取消时保留旧位置。
- 保持图片、大视频、完成提示、成功记录和开关行为；成功关闭文件后才显示完成并写记录。
- 官方 Button Group 源码按现有 Radix 体系选取，固定来源版本并登记必要本地差异，复用主题，不重设计外观。

## 排除项
不接 chrome.downloads，不新增下载权限，不自动创建固定目录，不接 Desktop，不改变媒体取流架构，不整段缓存大视频。不修改已暂停的官网日志，不提交、推送或发布。

## 验收标准
- 在图片及视频预览中打开下载按钮组，不点下载而直接退出预览（关闭按钮、Esc 或其他 TG 关闭方式），入口和下拉菜单不残留；重新打开预览后右键仍可用，已开始下载不因退出预览而中断。
- 默认只显示快速下载和横向三点按钮；横向三点菜单包含另存为、重新选择。
- 已有授权目录时快速下载直接保存；首次无目录可选择后继续，取消不误报成功，同名不覆盖。
- 另存为可独立选择文件名和位置，取消不下载、不写成功记录，不改变快速下载目录。
- 重新选择只改变后续快速下载位置，取消保留旧目录。
- 图片和分段视频仍流式写入；失败不误报完成，成功提示与记录保持正确。
- 用户加载 dist/build/chrome-mv3，在 Chrome 或 Edge 检查按钮组、横向三点菜单、目录授权、另存为、图片及大视频完整性；代理不执行视觉或交互验收。
