## 目标

## 范围

- 共享页头固定顶部，轻微透明背景与毛玻璃、淡分割线；共享页脚固定底部，保留版权署名和较实背景，不加分割线。
- 两页统一预留上下空间，首页保留既有标语、下载和 Logo 关系；更新日志最后一条可完整阅读，年份点击定位避开页头。
- 明确并统一标题、正文、年份、月日、标签和版权文字的字号与颜色层级，以及内容宽度、左右边距、条目间距和标签间距。
- 年份使用深灰与中等字重，月日保持灰色普通字重；保留黑底白字平台标签独立一行与无序列表。
- 优先复用现有主题与共享组件，仅提取实际复用的样式规则，不新增业务依赖或通用设计系统框架。
- 新建 docs/website-ui.md 作为官网视觉规则的唯一维护位置，记录字号、字重、颜色、间距、宽度、固定区域、锚点偏移与现有组件使用边界；具体数值确认后写入。
- 官网 README 与 apps/website/AGENTS.md 链接到该规范，Issue、Commit 记录引用同一规范，不在多处复制规则。
