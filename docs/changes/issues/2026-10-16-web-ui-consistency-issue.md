## 背景与目标

核实官网与扩展的通用组件来源，采用兼容现有技术栈的 shadcn 官方基础；通过主题、variant 和必要差异保持当前功能与风格。建立适用于两个应用全部 Web 功能的规范层级。

用户追加明确：通用控件能用官方就用官方；只有确认官方没有合适组件、组合或必要定制仍不能满足需求时，才考虑自行封装近似且一致的风格。该顺序已写入根规范，自行封装须记录官方方案不适用的原因。

## 已批准的视觉基准与取舍

- 目标是采用 shadcn 官方组件基础并减少维护成本，现有样式已满足需求，不进行视觉重设计。
- 视觉基准为本工作项改动前的已有实现及用户已确认的效果；不能把本轮替换后的默认外观当作新的基准。
- 官方默认样式与现有效果接近、不明显改变整体观感或操作反馈时，直接沿用官方，不为细微差异额外维护一份样式，也不要求逐像素复刻。
- 官方默认样式与现有已确认效果差异明显时，以现有样式为准；采用官方组件结构与行为，通过主题 Token、variant 或组件内必要定制保留效果。不得因采用官方组件而要求用户接受明显视觉变化。
- 明确例子：Sheet 采用官方组件基础，但遮罩继续使用现有主题透明色与 8px 模糊，浅色白色 42%、深色近黑色 62%；不换成官方默认黑色半透明遮罩。保留已确认的 560px 宽度、关闭按钮、主题和打开/关闭效果。
- 必要差异集中维护在主题和通用组件，不在业务页面复制；来源表说明保留原因。仅当差异判断存在真实歧义或必须改变已确认效果时，再向用户说明具体差异。
- 代理按源码、Token 与配置核对实现；实际视觉、布局、焦点和浏览器交互仍由用户在 Chrome/Edge 验收，不增加截图、假 DOM 或视觉交互测试。

## 范围

- 最新统一边界：风格规范统一覆盖官网与整个 Extension，包含 Newtab 与后续新增 Web 界面，新增界面复用已有主题和通用组件；Desktop 尽可能使用 SwiftUI／平台原生组件，本轮只同步选型规范，不调整 Desktop 代码或视觉。三端共享品牌与基础设计原则，官网与 Extension 的不同用途仍可保留参数差异；本轮不引入跨应用样式包或统一全部数值。
- 扩展 Switch、Button、Tooltip、DropdownMenu、Separator、Sheet，官网 Tooltip；核实官网 Button、Badge。
- 清理重复 Dock 外壳样式，核对业务模块边界；同步根规范、应用规范、UI 文档和来源说明。
- 保留授权时机、持久化、跨页同步、错误和禁用状态、主题、文案、焦点及 Tooltip 抑制行为。

| 扩展 Sheet | 手写右侧 Dialog 包装 | 采用官方组合基础，保留模糊、宽度、关闭按钮与动画 |
| 官网 Tooltip | 直接 Radix 包装 | 采用官方基础，保留无箭头外观及延迟 |
| 官网 Button、Badge | 对照官方实现一致，本地工具路径不同 | 保留，不作无必要改写 |
| 官网 module-showcase | 原生 button 与专用窗口布局、反馈 | 保留；套用 Button 需覆盖大部分默认样式，无实际复用收益 |
| history-cleaner/Newtab | 模块持有设置视图，Newtab 组合 | 边界正确，不调整归属 |
| 根/应用/UI 规范 | 原则局限 Newtab，白名单与模拟 Switch 规定过时 | 根维护选型原则，应用维护差异，移除冲突与重复规定 |

## 用户验收步骤与限制

1. 在专用 Chrome/Edge 配置文件的扩展管理页开启开发者模式，加载本次生产构建 `dist/build/chrome-mv3`。不要加载旧的 `dist/dev/chrome-mv3-dev-stable`：本轮没有启动开发服务或更新稳定开发目录。
2. 打开新标签页 → Settings → Browsing history。确认文案、右侧 Sheet、关闭按钮、遮罩与既有风格一致；开关具有名称与说明，未配置时关闭。使用 Tab/Space 操作，并确认加载或保存期间不可重复操作。
3. 开启开关，确认授权且持久化后才开启，开启本身不清历史；Chrome 可以静默授予 browsingData，无弹窗也属正常。打开第二个新标签页，切换开关，确认两页同步；刷新后保留实际配置。撤销权限后应关闭并就地提示；若可复现拒绝授权或保存失败，应保持真实状态并显示错误。错误与权限流程未由代理在浏览器实测。
4. 确认 Dock 的工具、Settings 和 EDU 入口风格未变；明暗系统主题下检查开关、Tooltip、菜单、Sheet、分隔线。菜单打开时不残留 Tooltip，关闭 Sheet 恢复焦点时不自动显示 Tooltip，再次主动悬停仍可显示。用键盘打开菜单、方向键移动、Enter 激活、Esc 关闭；外部点击关闭正常。
5. 在 100%、125%、150%、200% 缩放及较矮窗口检查菜单可见、必要时可滚动，Sheet 不超出屏幕。代理未验证布局、焦点、碰撞或主题外观。
6. 用户按需运行 `pnpm web:dev`，访问终端显示的本地地址，检查首页、`/features/`、`/changelog/` 的页头提示、按钮、标签与导航；叠放窗口点击、轮换及暂停行为保持原样。代理未启动服务、未部署或访问线上结果。
7. 核对根 AGENTS 的跨应用原则、两端 UI 文档及固定来源表。用户确认之前保持待验收；本次不提交、不推送、不部署。
