## 背景与目标

Daily 已通过 QueryDataTable 接入真实查询，但字段展示与筛选配置分开维护，原先没有统一编辑能力。本轮使用已有接口返回的数据验证“行末 Edit → Sheet 回填 → 字段校验 → 保存后更新当前列表记录”，不造数据或调用写接口；将共同流程纳入业务表格组合层，避免每个业务页面重复维护表单字段与操作状态。

## 范围与排除项

- columns.tsx 是 Daily 字段定义入口：复用列字段标识、字符串标题和顺序，通过 meta 声明筛选、编辑控件及校验；未声明 edit 的列不可编辑，不从 cell 的展示文本反向解析值。筛选配置不再在 Daily 页面重复维护。
- query.ts 是数据适配入口：继续使用原有真实查询接口返回的记录，不造种子数据，不建立替代查询数据集。编辑只修改当前返回记录的前端变量/状态，不调用写接口或持久化；重新查询、翻页或刷新重新以接口返回值为准，保留既有真实查询行为覆盖。
- daily-records.tsx 保持薄组合，账号及现有 Studio 访问边界不变；临时编辑状态跟随账号/会话作用域清理，不跨账号共享。不改变 Home 图表的数据来源。
- 共用表格组合层按更新能力生成操作列与 Edit；维护 Sheet 的回填、草稿、校验、提交中防重、失败保留输入、成功关闭及当前记录更新（临时预览不重新请求覆盖刚修改的值），不让资源层复制关闭/toast/reload 等流程。
- 支持本轮必要的日期、数字和基础文本输入；必填、正则及错误文案、整数、数值上下限等通过明确字段配置实现，复用官方控件，不构建通用规则语言或额外表单引擎。Daily 日期只读；五个时长使用分钟原始值，空值保留 null，0 保留明确零，不强行全部必填。不设置未经用户确认的演示上限，移除人工 600/960 限制。
- 编辑未保存时关闭按钮、Cancel、遮罩和 Esc 采用同一放弃确认；无改动直接关闭。交互规范统一：表单类任务使用 Sheet，提示/确认和简单操作使用 Dialog，删除及放弃修改等有损确认使用 AlertDialog。只更新规范，不批量改造已有登录或其他界面。
- Daily 临时编辑只作用于当前返回数据，未写入账号；保留真实服务端查询、排序、分页、null/0 语义，不伪造总数或重排服务端当前页。
- 确认旧 table-demo 示例只有开发入口使用后，移除旧示例页与该入口；不扩大为全仓库死代码清理。
- 排除项：真实更新 API、权限/数据库变更、新增/删除/批量编辑、行内编辑、新依赖、其他应用改造、浏览器视觉/交互自动验收、Git 提交/推送/发布。
