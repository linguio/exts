# 修复插件退出时的令牌撤销

## 元信息

- 已批准范围依据：用户确认退出应省略网页 Cookie；随后要求登录成功和失败都在右下角提示，并在成功后显示头像、昵称和邮箱。退出没有回调页，成功后提示「退出成功」。用户指定已登录账户改为 [shadcn Blocks](https://ui.shadcn.com/blocks) 的 dashboard-01 `nav-user`：登录后向右展开，退出放在菜单里，不再用弹出框。

## 背景与目标

Studio 退出时向 Neon 撤销刷新令牌。该请求带上了登录窗口留下的网页 Cookie，来源仍是 chrome-extension，Neon 返回 403 INVALID_ORIGIN。撤销失败后本地身份保留，界面一直显示已登录。

## 范围与排除项

- 范围：插件退出的撤销请求省略 Cookie。登录成功后读取用户信息并显示头像、昵称和邮箱；登录成功、失败和退出成功都用右下角提示。已登录账户使用 dashboard-01 的展开菜单，Log out 直接退出。失败仍保留原身份并允许重试。
- 排除项：不迁入 dashboard 的图表、表格和其余示例页；未登录仍用现有登录框。Account、Billing、Notifications 不新增功能。不改官网页面、Neon 控制台配置，不退出 GitHub 或官网会话，不把令牌写入日志或仓库，不推送。
