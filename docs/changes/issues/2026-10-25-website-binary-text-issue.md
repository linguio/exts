## 背景与目标

官网「将想法与能力延伸为实用工具」目前为静态文字。参考 Binary Text 效果，让字符从 0、1 逐个还原为原文，保持现有文案、字体、布局和主题。

独立 HTML Demo 已展示，包含重播、速度选择与悬停开关；这些演示控件不属于官网交付范围。Demo 位于临时目录，不作为仓库依赖或正式产物。

## 范围

- 仅为官网上述介绍文字增加二进制解码动画，不修改 `site.subtitle` 的原始文案与页面元信息。
- 使用 React/JavaScript 拆分字符并生成动画序列，CSS 负责分步翻动与字符错峰；不引入动画库。
- 首次挂载播放一次，结束后保持正常文字；节奏以已展示 Demo 的标准档为参考。
- 固定字符占位，处理中文、空格与标点；沿用当前主题与排版，不改变其他标题或页面布局。
- 支持系统减少动态效果设置；辅助技术读取完整原文，不逐帧播报二进制字符。
- 独立实现效果，不复制 shadcn.io Pro 未公开源码，不将该站标注为 shadcn/ui 官方组件来源。

## 排除项

- 不修改 Extension、Desktop、后端、数据库或账号功能。
- 不增加官网重播按钮、速度选择、悬停开关或动效设置面板。
- 不扩展为全站动画系统，不引入新依赖，不变更产品版本。
- 不自动提交、不推送、不部署。

## 验收标准

- 用户打开官网首页时，目标文字按确认的触发方式从二进制序列还原为「将想法与能力延伸为实用工具」，结束后保持可读，不持续循环。
- 原有字号、字重、颜色、换行及周边布局保持；动画过程中无明显占位跳动或截字，明暗主题均可读。
- 开启系统减少动态效果后直接展示原文；辅助技术只读取完整原文。
- 官网不出现 Demo 的速度、重播或悬停控件，其他页面内容不变。
- 自动化验证仅覆盖必要纯逻辑与构建，不新增截图、像素、布局或交互测试；视觉、节奏与交互由用户在 Chrome/Edge 验收，测试通过不代表用户验收通过。
