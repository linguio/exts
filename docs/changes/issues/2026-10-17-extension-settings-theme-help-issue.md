## 背景

## 范围与设计

### 设置分区

- `General`：基础配置，目前包含 `Theme`。
- `Features`：功能配置，目前包含历史清理。
- 两区之间使用现有 Separator；不再为历史清理额外叠加 Browsing history 标题，保留开关标题 `Clear history on startup and close`。
- 沿用现有英文文案、Sheet 宽度、遮罩、关闭动画和入口交互，不新增 Dock 入口。

### 主题切换

- 在 Theme 行右侧使用 shadcn 官方 ToggleGroup 的单选组合，三项横向平铺，分别为 Light、Dark、System；只显示太阳、月亮、笔记本（LaptopMinimal）图标，不显示选项文字。
- 图标沿用现有 Lucide 静态导入和 UiIcon 入口；控件使用现有主题 Token、圆角、焦点和手形反馈，选中项明确区分。不得手写三个 Switch 模拟单选控件。
- 图标具有可访问名称；悬停和键盘聚焦时，复用现有 Tooltip 显示简短名称，不另加独立帮助图标或说明段落。
- 默认 System，始终保持一个选项；再次点击当前项不能取消全部选择。
- 选择立即生效并保存到本机，刷新及重新打开页面后保留；已打开的新标签页同步更新，不做跨设备同步。
- System 跟随系统主题变化；手动 Light/Dark 不被系统变化覆盖。
- 复用现有浅色和深色配色，统一作用于页面、图标适配、菜单、Tooltip、Sheet 与遮罩；处理首屏主题初始化，避免已保存深色却先显示浅色的闪烁。
- 主题偏好与应用逻辑由扩展共用层持有，Newtab 组合设置入口，不把主题业务状态放入 shared/ui。后续扩展页面可复用，不为未来页面预建额外框架。

### 历史清理帮助

- 在历史清理开关标题旁增加独立圆圈问号图标按钮，复用 Button、Tooltip、UiIcon，不自行实现弹层或重复封装帮助组件。
- 移除常驻说明段落，将以下原文完整放入 Tooltip，保持现有主题风格；最大宽度约 280px，自动换行，优先在图标上方显示并允许碰撞调整：

  > Clears all browsing history when the browser starts and the last window closes. Cookies, cache, and downloads are kept.

- 帮助按钮支持悬停和键盘聚焦，不触发开关；说明仍须能作为开关的读屏描述，避免移除段落后 aria-describedby 失效。
- 错误提示继续在设置区域直接展示，不隐藏到 Tooltip。
- 历史清理继续默认关闭，保留现有已保存的用户选择；只在用户主动开启且成功取得权限后生效，不因主题、分区或提示迁移自动开启。
- 保留可选权限、保存、跨页同步、禁用及错误反馈；不修改后台清理范围或生命周期逻辑。

## 浏览器反馈与只读调查

用户截图显示：浏览器自带深色下页面、卡片、Dock、Sheet 一致；手动 Dark 下只有背景变黑，其他区域仍浅色。本阶段未验收通过。

只读核对当前源码、生产 CSS 及现有开发服务：源码和生产构建包含根 data-theme 深色 Token 与图标规则；稳定开发 HTML 引用 localhost:3001，直接读取该服务的 /src/styles/index.css，返回内容仍包含 prefers-color-scheme 深色媒体查询，完全没有 data-theme 规则。因此当前服务样式不响应手动属性切换，而浏览器偏好变化仍能触发旧深色规则；HTML 首屏背景已有 data-theme 规则，导致只变背景的混搭。这是服务提供的样式与当前源码不同步的证据，不是重新设计了两套深色配色。

进一步只读检查确认服务运行目录及 CSS 模块标识均指向当前扩展。同一路径的普通请求仍返回媒体查询规则，而 ?direct 和独立模块请求返回当前 data-theme 规则，定位为开发服务的 CSS 模块缓存未同步，不是错误运行目录。用户补充浏览器深色下手动切浅色无效，也符合页面仍由该媒体查询控制的现象。
