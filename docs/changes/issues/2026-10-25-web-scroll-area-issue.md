# 接入官方滚动区域组件

## 元信息

- 创建日期：2026-10-25

## 背景
Download 当前使用原生 overflow-y-auto，官网与扩展还有其他内容滚动区域。用户要求按项目 UI 规范采用 shadcn/ui 官方组件，统一可控滚动区域，不自行设计滚动条或维护额外样式。

## 目标
采用官方 Scroll Area 及其默认滚动条，统一适用的内容容器，保留现有布局、内容与原生滚动操作。

## 范围
- 按用户补充要求更新根 UI 规范，明确滚动区域同属官方优先原则，并同步官网、扩展 UI 说明；不另建一套独立选型制度。
- 盘点官网与扩展的内容滚动区域，按实际容器接入，不以全局 CSS 覆盖所有原生滚动条。
- Extension 候选区域：Download 列表、Settings 内容、Newtab 书签区与卡片区、Dock 横向滚动区。
- Website 候选区域：产品说明中的安装命令横向滚动区；页面主体滚动须先评估，默认保留文档滚动语义，不为换外观重构页面根布局。
- 引入官方 ScrollArea / ScrollBar 源码，沿用项目现有 Radix 和主题体系，固定官方来源版本，登记最小必要适配。
- 采用官方默认外观与状态，不额外定制滚动条宽度、配色、显隐或动画；不增加无关依赖、抽象或状态变量。
- 接入时保留现有容器尺寸、滚动方向、空状态、内容间距、截断与业务行为；删除被替代区域不再需要的隐藏滚动条样式。

## 排除项
- 不修改 Chrome/Edge 自身、Telegram 原网页或 macOS 原生界面滚动条。
- DropdownMenu 等官方组件内部已有滚动机制，保持其官方实现，不额外嵌套 ScrollArea。
- 不改变下载记录、筛选、清空、主题持久化、TG 保存流程或官网文案；不升级产品版本。
- 不自动提交、推送、部署或发布。

## 验收标准
- Download、Settings 及确认纳入的其他内容区域使用官方滚动组件，不另造滚动条样式。
- 内容超出时可滚动；没有溢出时无多余滚动条，不出现双重滚动或内容不可达。
- 空列表仍保持现有居中效果；长文件名与长命令不撑破面板，Dock 横向滚动正常。
- 明暗主题、鼠标滚轮、触控板、键盘及滚动条拖动由用户在 Chrome/Edge 验证；代理不执行视觉、布局或交互验收，不新增相应模拟测试。
- 不影响菜单原有滚动、页面主体滚动及已完成的下载功能。
