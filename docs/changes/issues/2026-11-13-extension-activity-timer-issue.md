# 在活动日历上方增加翻页倒计时

## 元信息
- 工作项：2026-11-13-extension-activity-timer
- 状态：已完成
- 规模：小型单目标功能；新增官方 Slider 依赖及本地时钟切换。
- 批准依据：用户逐项确认布局、5 分钟步进、声音、通知及内存状态后要求开始。

## 背景与目标
在首页卡片区左列、日历正上方加入翻页倒计时，沿用文件夹及日历卡片的主题、边距、圆角与外框。

## 范围
- 顶部官方 shadcn Base UI Slider，右侧模式图标同一行；0–60 分钟，手动选择步进 5，松开自动开始；再拖动替换原倒计时，0 停止。
- 运行时按截止时间计算剩余秒数，Slider 连续缩回；不再显示右侧分钟数。
- 时钟HH:mm和倒计时MM:ss共用两张等大双位翻页卡，字号、尺寸、位置不变；无开始、暂停、重置按钮。
- 选定的合成滴答与完成音，归零只提醒一次：英文 Sonner，不发送系统通知。
- 移除 notifications 权限及请求。图标在 Clock/Timer 两态切换：清空倒计时后显示系统本地 HH:mm，数字改变时翻页、不显示秒、不滴答；再次点击自动从25:00开始倒计时，拖动Slider自动切入倒计时。初始默认展示系统本地HH:mm。
- 状态由 timer/use-countdown.ts 在 TimerCard 内用 React 内存/ref 持有；Home/Studio 切换保留，关闭或刷新清空，多个 Newtab 独立。

- 用户补充批准右键声音菜单：指定官方Base Context Menu默认分组/勾选，英文Timer Sound与Completion Sound；按短到长排列的Pink Noise/Brown Noise/Metronome/Quartz Clock和Harp/Glass Chime/Soft Three-Tone（计时四种，完成三种）。
- 默认Quartz Clock＋Glass Chime，声音偏好存chrome.storage.local；更换立即试听（滴答3次、连续噪声3秒、完成音1遍），取消旧试听、不重叠、不重置倒计时，结束恢复运行声音。

## 排除项
不持久化、不跨标签页同步、不写 Activity 记录、不增加后台持续计时或全局 Store，不改变日历查询与统计。视觉和真实交互由用户验收，不增加 DOM 模拟或浏览器交互测试。

- 手动 5 分钟吸附、松开开始，运行平滑回缩，显示正确分秒；拖至 0 可停止。
- 原 Demo 两阶段翻页保留，分缝为 1px，沿用主题。
