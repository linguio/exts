- 规模：小型，一个 Issue，以 Todo 管理

## 背景

用户反馈 Newtab 打开设置抽屉时主题 Tooltip 自动激活。当前 Sheet 未指定打开焦点，主题选择是内容中的首个可聚焦控件，自动聚焦会触发 Tooltip。

## 目标

打开抽屉时先聚焦 Settings 标题，避免自动显示主题提示；主动悬停和键盘聚焦主题按钮仍显示提示。

## 范围

- 仅在 DockSettings 中配置标题引用、程序化聚焦和打开焦点回调。
- 标题不进入常规 Tab 顺序，保留 Sheet 焦点约束、Esc 关闭与关闭后的焦点恢复。
- 同步本 Issue、Commit 记录及工作台，并执行扩展测试、类型检查、生产构建、体积和 diff 检查。

## 排除项

- 不修改主题逻辑、Tooltip 通用组件、外观、依赖或历史清理功能。
- 不引入假 DOM 或焦点交互测试；浏览器交互由用户验收。
- 不推送、不部署，不启动开发服务；本地提交已由用户在阶段交付后单独批准。

## 用户验收步骤

1. Chrome/Edge 扩展管理页加载本次生产产物 `dist/build/chrome-mv3`，重新打开新标签页。若使用已有开发服务，重新加载稳定目录 `dist/dev/chrome-mv3-dev-stable` 后关闭旧新标签页再打开，确认服务已更新源码；本次未启动开发服务。
2. 点击 Settings 并将指针停在非主题区域，预期打开后不自动显示 Light/Dark/System 提示，已选主题不变；关闭并重复打开确认。
3. 主动悬停主题按钮，再移开鼠标使用 Tab 聚焦主题按钮，预期均能显示名称，主题切换正常。
4. 用键盘 Enter/Space 打开 Settings，预期不自动弹主题提示；Tab 能进入抽屉控件，Esc 和关闭按钮均可关闭，关闭后入口不自动弹提示且可再次打开。
