# 新增工作台切换与快速开始入口

## 元信息
- 状态：已排队
- 创建日期：2026-10-26
- 项目：extension
- 当前阶段：需求已整理，未开始实现。

## 背景
首页继续承担书签与卡片展示；新增与 Exts 一体的工作台，为后续数据管理预留主视图。保留 Dock 向上弹出列表的交互，Components 资源迁入 UI 后，其位置改为快速开始。

## 目标
在同一 Newtab 内切换首页与 Workspace，Dock 保持可用；新增 Zap 快速开始菜单，只展示占位内容。

## 范围
- 新增独立 workspace 模块，承担工作台主视图；本期只显示 Workspace 标题与基础空状态，不添加侧栏、统计卡片或业务导航。
- Dock 右侧仍命名为 tools，左侧仍为 favorites；新增 Workspace 入口，固定使用 PanelsTopLeft 图标。
- 同一入口点击切换首页与工作台。首页 Tooltip 为 `Switch to Workspace`，工作台 Tooltip 为 `Back to Home`；可访问名称同步使用相同英文目标动作。
- 工作台打开时沿用官方组件已有的选中反馈；不切换成 House，不给线条图标额外加 fill，不自行增加一套选中配色。
- Dock 在两个视图中保留，下载与设置继续使用原抽屉；首页现有布局保持不变，切换不重置可保留的视图现场。
- 新标签页首次打开默认首页，不将工作台状态持久化成新标签页默认入口。
- 移除原 Components 菜单残留，原位置改为 Zap 图标的「快速开始」，保留向上弹出列表。
- 快速开始暂不放新建 Issue、记录打卡等具体业务入口，只放两个带图标的中性占位项。按本轮整理建议使用 `Placeholder A`（List）与 `Placeholder B`（FolderOpen），显示未开放并使用官方菜单禁用状态，不执行创建、跳转、网络请求或伪成功反馈。
- Workspace 的 PanelsTopLeft 与快速开始的 Zap 接入共用 UiIcon 显式静态导入；占位项复用已有 List、FolderOpen，不引入整套图标注册表或独立品牌 SVG。
- Dock 右侧顺序按已讨论方案为 Workspace、快速开始、下载、设置。

## 排除项
- 不实现 Issue、打卡或日志业务，不接入登录、Hono、Neon、Vercel 或其他外部服务。
- 不把工作台打开为抽屉、独立网站或新浏览器标签页。
- 不迁移书签图标或重复实现 UI 文件夹；相关内容由前序 Issue 交付。
- 不重构其他模块，不调整 Dock 收藏区或现有下载、设置功能。
- 不新增视觉、布局、Tooltip、菜单、键盘或焦点类自动化测试；此类验收由用户执行。
- 不提交或推送。

## 验收标准
- 打开新标签页默认首页；点击 Workspace 在同页切至工作台，再点击回首页。
- 图标始终为 PanelsTopLeft，提示表达点击目标，选中反馈表达工作台当前状态；两种主题均复用现有体系。
- 切换后 Dock 始终可用，下载、设置仍可打开；首页原有状态不因不必要的卸载而重置。
- 原 Components 菜单被 Zap 快速开始替代，列表有两个带图标的禁用占位项，清楚显示未开放，不出现已定义业务入口或触发实际业务行为。
