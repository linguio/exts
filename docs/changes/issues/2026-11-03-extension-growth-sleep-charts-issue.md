# 展示成长打卡与睡眠趋势

## 元信息

## 背景与目标
现有 Activity 卡片只有空记录日历及空图表视图。用户批准以模拟数据展示个人成长完成情况、长期投入与睡眠趋势，以及周投入和周目标完成度。

## 范围与设计
- 日历保留最近 24 周、周日开始；运动、阅读、学习、创作各每日累计满 30 分钟算完成一项，每项最多一次，按完成 0–4 项显示灰阶。提示只显示日期与四项时长，不显示合计或完成数统计行。
- 成长与睡眠柱状图共用截至昨天的最近 14 个自然日，不包含今天；横轴逐柱显示不带前导零的日号。成长每日一根堆叠柱，按实际分钟数；从上到下运动、阅读、学习、创作。缺项省略色块，未达标时长仍进入图表。
- 柱状图右上角用现有 ChevronsUpDown 图标及 Button ghost/icon-sm，点击直接轮换成长/睡眠，默认成长；Hover 以 Growth/Sleep 表示当前分类，无下拉菜单。睡眠仅保存每日总分钟数，无午睡、入睡或起床字段。
- 成长水平虚线为当前 14 个自然日总投入除以 14，无投入日期按 0 计；不显示常驻文字。与睡眠 7 小时线均使用官方 ReferenceLine，当前没有独立 Hover 数据提示。
- 睡眠柱按 <6h、6–<7h、7–9h、>9h 映射 1–4 档；水平虚线固定 7 小时且不显示文字，不计算均值；缺失留空。颜色只代表时长区间。
- 日历 Tooltip 使用官方 disableHoverableContent 选项，关闭触发点到提示框的鼠标过渡区域，避免阻塞连续移入相邻格子；其他 Tooltip 不变。
- 用户进一步批准活动卡片全部数据提示统一复用官方 ChartTooltipContent 外观和行布局；日历保留官方 Tooltip 触发/定位，内容使用同一 ChartTooltipContent，不修改卡片外其他普通 Tooltip。
- 用户截图显示柱状图横轴日号下沿裁切；XAxis 20px 预留不足以容纳默认 tickSize、6px tickMargin 与文字，调整为 28px，卡片和图表总高度不变，由用户复验。
- 周视图按周日至周六、本地日期统计。左侧实心饼图按用户提供 ChartPieSimple 源码不设置 innerRadius，表示四项实际时长构成，从 12 点顺时针运动、阅读、学习、创作；右侧四个同心环由内到外同序，展示各自周计划完成度。两图不显示“投入/计划”标题，保留可访问名称和统一 Tooltip。
- 计划环颜色按完成比例分档，不再固定绑定分类：0%用muted，(0,25%]、(25%,50%]、(50%,75%]、>75%分别为chart-1至4，超额保持4档。继续复用全局 chart 灰阶，左侧饼图仍按分类固定配色。
- 周目标固定运动 180、阅读 300、学习 600、创作 900 分钟。进度环最多一圈，提示保留实际百分比（包括超过 100%）。
- 按用户最新要求移除周视图顶部的周日期范围标题（如11-01–11-07）；内部周范围统计保留，Tooltip不显示日期范围。
- 最新Tooltip规则：周视图仅以“本周投入/本周计划”为标题，不显示周日期范围或progress技术字段；Hover任一扇区/环均显示四项完整明细（含0值），按固定顺序，当前项整行加粗。投入显示占比/投入时长，计划显示完成率/目标时长。
- 全部时长使用小写h，最多一位小数，整数不保留.0，如0h、5h、1.3h；本周投入每项为30% / 5h，本周计划每项为120% / 10h。日历/柱状图保留日期和明细，无合计/完成数行。只改展示，不改变原分钟数据、完成门槛或统计。
- 用户批准两类柱状图都使用圆角，采用4px：睡眠Bar使用共用CHART_BAR_RADIUS，成长使用Recharts官方BarStack对整根柱外轮廓设同一圆角，内部接缝直角；缺项/单项/薄色块由官方实现处理，不自写shape、clip或使用已弃用Cell。
- 用户批准按提供ChartRadarDefault示例在周视图最右侧试加四轴雷达图，顺时针为运动/阅读/学习/创作，使用周计划完成率，0–100%固定域，图形封顶而Tooltip保留超额比例。三图同排保持原卡片宽高，不新增常驻标题或示例Card/页脚；复用完整四项Tooltip、悬停加粗及百分比/目标h文案。沿用PolarAngleAxis/PolarGrid/Radar及0.6填充透明度。按用户最新“太小、不要标题”反馈，半径改为44px并隐藏轴文字，名称在Tooltip保留；实际可读性由用户试用验收。
- 所有分类和睡眠统一引用全局 --chart-1 至 4，日历 --activity-level-1 至 4 仅映射它们，第 0 档与环轨道用 --muted。用户批准替换原手工 HEX：浅色 OKLCH L=0.64/0.50/0.36/0.22，深色 L=0.52/0.66/0.80/0.94，C=H=0。明暗分别等步长 0.14，核算卡片/轨道背景与相邻对比并写入 UI 规范；不声称完成视觉验收或所有相邻档满足 3:1。
- 复用现有外框尺寸、材质与三项图标切换；官方 Chart 及用户提供示例作为实现基础，仅进行已批准业务内容、布局及主题适配，不添加示例标题/访客数据/页脚或额外 Card。
- 固定 JSON 覆盖缺项、未达标、全部完成、超额、睡眠分档及缺失记录；运行时不随机，不录入、不联网。
