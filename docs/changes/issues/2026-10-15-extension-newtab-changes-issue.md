## 背景

首页文字与下载按钮距离过大，内容分散；共享页脚固定在视口底部；更新日志的标签单独占行，工具包说明需要按产品用途与发布内容分别表达。

本工作项最初以 newtab 为题建立，后续实际讨论均为官网优化。现以用户最后确认的内容为准，统一整理为官网工作项，保留既有文件前缀和关联关系；没有明确的扩展 newtab 需求，不修改扩展。

## 目标

让官网首页介绍和下载入口更集中饱满，统一各页页脚逻辑，完善产品说明与更新日志表达。本轮是对既有官网展示的一次整体调整，不额外增加功能或独立阶段。

## 范围与已确认设计

### 首页文字与下载区域

- 参考用户提供的 VitePress 截图，采用更饱满的字号层级和紧凑排列，保留官网现有黑白风格。
- 桌面参考值：Exts 约 56px，标语约 40–48px，介绍约 20px；数值是调整起点，以现有栏宽、自然换行和左右视觉平衡为准，不把 Exts 和标语同时放到最大。
- Exts、标语、介绍与两个下载按钮组成紧凑整体，统一左对齐；按钮并排、紧跟介绍，不再被推到左栏底部角落。
- 通过整体外围留白与右侧既有展示保持平衡，不将各行强行等距拉开；保留既有工具分类卡片和产品轮播展示。
- 手机端相应缩小字号，文字自然换行，按钮空间不足时换行；内容不足以放入一屏时自然滚动，不通过裁切或强制压缩维持一屏。

### 所有页面的共享页脚

- 首页、Changelog、产品说明共用同一套 Footer 和布局，不逐页增加特殊逻辑。
- 取消固定定位：短页面通过共享页面布局将页脚撑到屏幕底部；长页面在正文后显示，随页面正常滚动，不悬浮遮挡正文。
- 删除原先为固定页脚保留的底部占位，保留合理正文间距与必要安全区。
- 删除 `Released under the MIT License.` 整行和对应链接，仅保留 `Copyright © 2026 Lin Gui`；不改许可证文件。
- 固定页头保持现有行为，同步 `docs/website-ui.md` 中受本次调整影响的布局、字号和页脚规则。

### 产品说明中的 WXT 工具包

- 标题使用“WXT 稳定构建产物工具”，纯文字不加超链接；真实包名只保留在安装命令和地址中。安装命令下方并排放“npm 包”“查看源码”，npm 指向包主页，源码指向现有仓库目录，不设置下载链接或下载按钮。
- 用途说明简化为：为 WXT 开发模式提供稳定的扩展加载目录，避免重建或构建失败导致扩展加载异常。
- 提供安装命令：`pnpm add -D @linguio/wxt-stable-output`。

### Changelog 排版与工具包条目

- 每条日志的标签放到标题后，同一行排列；空间不足时自然换行，不固定另起一行。
- 原“WXT 稳定产物工具首次发布”标题改为“发布 WXT 稳定构建产物工具”。保留该历史条目的原日期，不改成今天。
- 该工具包条目不添加概述正文，直接显示以下两条改动，只保留以包名和版本 `@linguio/wxt-stable-output · 1.0.0` 为文字的 npm 链接，指向该条日志对应的具体版本，不提供源码入口：
  - 转发 WXT 重载通知前，先同步最新构建产物到稳定加载目录。
  - 校验或目录替换失败时，保留最后一次成功的产物，并提供错误信息供排查。
- 删除该条目中源目录与目标目录重叠、ESM 入口及 TypeScript 类型声明的说明，不将这些接入细节放在官网发布日志中。

### 辅助链接样式

- 产品说明与 Changelog 使用统一的小字号文字链接、下划线、悬停和键盘焦点样式，不使用 Button。文字右侧使用现有 Lucide ArrowUpRight 小图标，图标对辅助技术隐藏，链接保留真实锚点与外链安全属性。

## 验证与验收标准

- 代理仅检查必要逻辑、内容配置、类型和构建；针对性验证后，在阶段完成时执行一次官网完整测试、类型检查和构建。纯文档整理本身只核对内容、链接与 diff，不运行应用测试。
- 用户在 Chrome 或 Edge 打开首页：桌面文字更饱满，标题、标语、介绍与按钮形成紧凑整体，按钮紧跟介绍；现有下载地址、卡片与轮播功能保持可用。
- 用户缩窄窗口至手机宽度：文字和按钮自然换行，不横向溢出、不截断内容，页面可正常滚动。
- 用户分别打开首页、产品说明、更新日志：短页面 Footer 在屏幕底部，长页面滚动到正文结束后显示；均只显示 `Copyright © 2026 Lin Gui`，正文不被遮挡，无固定页脚留下的多余占位。
- 产品说明使用无链接的中文标题，显示已确认的用途和安装命令；命令下方并排显示带 ArrowUpRight 的 npm 包与源码文字链接，无下载按钮。Changelog 使用中文发布标题，仅提供对应历史版本的包名与版本链接，使用相同样式；安装命令只放在产品介绍中。
- 日志标签紧跟标题，窄屏自然换行；工具包条目标题与两条改动和本 Issue 一致，无额外概述；2026-10-15 条目的标题与三条内容和本 Issue 一致。
