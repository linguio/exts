## 范围

- 首页展示卡片标题与无障碍名称从 Tabs 统一为 Newtab。
- 共用产品分类数据使用以下确认文案，覆盖首页与产品介绍页面：
  - Newtab：在新标签页集中访问常用网站，整理分组标签。
  - History Cleaner：在浏览器打开与关闭时清理访问历史，保留 Cookie、缓存和下载记录。
- 同步官网说明和 UI 规范中的展示名称与模块清单。

## 排除项

不增加历史清理示意卡，不改变卡片轮换、页面布局或样式，不重命名内部组件、模块路径或稳定 ID，不改变扩展功能；不修改已确认的日志文案，不升级依赖。
