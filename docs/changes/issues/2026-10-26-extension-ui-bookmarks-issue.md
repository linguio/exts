## 背景
Components 中的开发资源将迁入首页，Dock 原入口后续改为快速开始。现有图标保留图案细节，只统一配色与资源位置。

## 目标
新增位于 EDU 前的 UI 书签文件夹，默认模糊，内部溢出可纵向滚动且不显示滚动条；相关 SVG 统一主题配色并集中到 brand。

## 范围
- 将 assets/tools 中现有五份 SVG（lucide、iconfont、antd、element-ui、element-plus）仅做颜色转换后迁至 assets/brand，更新活动引用与 WXT 资源注册；确认迁移完整后移除旧 SVG，不丢弃原始图案。
- 配色沿用已展示 Demo 的中性灰阶与明暗主题方向。保留路径、形状、线宽、比例、viewBox、内部留白、透明度和遮罩作用，多色图标保留必要的明暗层次。
- 统一配色覆盖迁入 UI 的全部七个图标，包含已在 brand 的 shadcn.io 与 Simple Icons；不扩展为全仓库图标重绘或改色。
- 新增 UI 文件夹，排在 EDU 前；迁入 Components 现有七个网站，保留网址和顺序：Lucide、shadcn.io、Iconfont、Ant Design、Element UI、Element Plus、Simple Icons。
- 内部排列沿用现有书签文件夹的图标网格与外框尺寸，不改成纵向名称列表。
- 默认模糊及解除模糊行为复用现有文件夹机制；内部内容溢出时上下滚动。隐藏滚动条仅适用于 UI 文件夹，优先使用现有官方 Scroll Area 能力，不引入另一套滚动条实现。
- 用户最新补充批准：上下两端使用 16px 悬浮渐变磨砂及 ChevronUp / ChevronDown；贴边 3px 用文件夹 card 背景色完全盖住内部图标边框，再向内容侧逐渐透明并减弱磨砂，上下镜像。文件夹自身外边框保持清晰，箭头不受渐变蒙版影响。只有对应方向还有内容时显示，顶部只显示下提示，中间两个都显示，底部只显示上提示，无溢出或默认模糊时都隐藏。不占布局空间、保留网格原有内边距；不依赖 Hover、不响应点击或阻挡滚动。
- 本 Issue 迁入 UI 后暂时保留 Dock Components 入口，同步使用迁移后的资源路径；移除入口与改成 Zap 统一由后续 Issue 交付，遵守用户指定的拆分边界。
- 用户批准移除 google-translate.png 的失效 WXT 注册，并在重新拆分提交时明确要求将该旧 PNG 的删除一起纳入代码提交。

- 不重排其他书签，不改变右侧卡片、Dock 收藏区或其他文件夹的滚动与模糊行为。
- 不接入 Workspace、后端、数据库或真实管理功能。
- 不执行浏览器视觉、布局或交互验收，不提交或推送。

## 已确认与现状约束
- 用户确认 UI 沿用现有排列，七个图标全部统一配色。
- 现有书签渲染区分 original 与 adaptive；adaptive 使用 CSS filter 在浅色显示黑色、深色显示白色，不代表 SVG 全部已改为 currentColor。
- 应用 AGENTS 与 V3 规范已有单色 currentColor 方向，但明确允许未调整旧资源保留原状；Exts 产品图标另有固定黑底白图规范。
- 本次按用户明确批准只改颜色、保留图案及多色图标的必要灰阶层次，不套用 V3 的重绘、统一 viewBox 或强制单一颜色要求。实施时记录此范围差异；不得用整体 brightness 滤镜抹掉已保留的灰阶或黑白对比。
