## 背景与目标

Dock 各入口分别处理 Tooltip 和焦点恢复，导致点击外部或 Esc 关闭后提示和描边不一致。统一使用共用 Hook，保留官方焦点恢复和后续正常键盘提示。

## 范围与排除项

- 范围：Account 登录框与菜单、Actions 菜单、Settings 和 Download 抽屉入口复用一个 Hook；关闭恢复焦点时抑制 Tooltip 和入口描边，重新操作后恢复；清理旧重复处理。
- Settings 与 Download 内部打开时聚焦标题继续保留。
- 已确认公共边界：菜单保留官方窗口失焦关闭，Dialog / Sheet 沿用默认行为，Hook 不增加 ⌘Tab 特殊处理。
- 排除项：不改官方组件、认证、菜单内容、下载与设置业务；不新增交互模拟测试，不自动提交。

## 验收标准

- 弹出层打开时入口 Tooltip 隐藏。
- 鼠标点击外部或 Esc 关闭后，不因焦点恢复重新出现 Tooltip 或入口描边；保留组件默认焦点恢复。
- 再次悬停、Tab 切换和键盘操作后正常反馈；四个入口均适用。
- Account 登录成功关闭后状态同步，Settings / Download 打开仍聚焦标题。
