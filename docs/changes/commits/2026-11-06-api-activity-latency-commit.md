## 实际交付

- 公共数据库模块统一连接池、启动预建、连接借还、错误映射、多步事务和单次只读合批；固定新增 psycopg-pool==3.3.3，沿用既有依赖版本。
- read_rows 在空闲连接上一次发送只读 BEGIN、参数、仓储 SELECT、COMMIT；已有事务中只读取，不替调用者提交或回滚。写入任务继续使用多步事务，不将只读批次套到写入。
- 启动后台同时准备数据库连接和公开验签公钥，公开入口不等待；缺失配置跳过、失败安全告警，退出等待任务并关闭池。连接 min/max=0/4、等待 5 秒、空闲回收策略 60 秒；公钥缓存仍为 300 秒，无周期保活或认证结果缓存。
- Activity 仓储合并用户存在与数据读取，保留 401/空记录区分、本人过滤、日期、NULL/0、时间戳和统一响应。认证、只读/读写、时区、超时及回滚边界保留。
- 前端沿用现有 lib/api/client.ts，不新增请求包装或修改 JSON。未采用的流水线实验已移除，生产代码没有测试执行器或测试模式。
- 2026-11-07 按用户要求整理导入和排版，清理无用测试模拟与宽松补属性参数；合并多轮文档为当前实现与有效证据，不改变行为。

- 三项隔离实库检查跳过，不记为通过；没有真实写入、删除用户、迁移或角色/云端设置变更。
