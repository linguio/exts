## 预期交付边界

Newtab 左侧书签、右侧固定列和底部 Dock 的三区布局；内部间距 24px，左右独立滚动且隐藏滚动条；右侧第一张占位卡片与文件夹预览外框等高、两列加间距等宽。整理 views 为 bookmarks、dock、cards 和 settings；右侧区域使用独立组件，第一张卡片使用 cards/check-in 独立目录与入口。仅布局与占位展示，不实现打卡业务或接口，不新增独立业务 module；用户已批准此范围实施。

Dock 撑满底部可用宽度后仅内部横向滚动，隐藏滚动条；上方左右区域的溢出内容只能在所属区域内滚动，包含展开后的文件夹，不得覆盖 Dock 或使页面整体滚动。

## 实际交付

- 页面改为上方左右两区与底部 Dock 行，保留原外圈留白及内部 24px 间距；左右独立内部滚动，Dock 撑满后内部横向滚动，全部隐藏滚动条。
- 右侧固定列由两个文件夹外框加间距计算，首张空卡片与文件夹预览外框等高；尺寸基准集中在主题，页面不承担具体卡片内容。
- Dock 三个视图文件移入独立 dock 目录；cards 区域入口与 check-in 卡片目录独立，保留 settings 与 bookmarks 的职责，不新增打卡业务。
- 引入固定版本 shadcn Card 根组件、记录来源与必要主题差异，同步 Newtab 与扩展 UI 说明；无新增依赖、版本或更新日志变化。
