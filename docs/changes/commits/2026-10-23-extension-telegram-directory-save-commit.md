## 预期交付边界

按用户 2026-10-24 最新要求，仅提供快速保存和选择文件夹；任意浏览器允许的目录均可，不限定 Exts 名称、不创建固定子目录。首次选好后立即下载，后续直接保存，并可单独更换位置。不包含公共下载记录、Newtab 列表、X 下载或 Desktop。

## 实际交付

- TG 菜单仅包含“下载资源”和“选择文件夹”，去掉独立另存为入口、常驻目录状态和帮助说明，保留必要错误恢复文字及成功完成 Toast。
- download-core/directory-target.ts 管理目录恢复、选择、权限及同名避重。首次 openFile 在当前点击栈内打开目录选择器，选好并记住后继续保存；已有选择直接写入。
- 第二项只更新后续目录，取消或持久化失败保留原选择。旧句柄继续表示当前保存目录，不迁移或删除历史文件。
- directory-store.ts 在 Telegram 同来源 IndexedDB 持久化句柄，事务完成后报告成功，异常关闭数据库；不进入扩展配置或公共记录。
- Web Locks 仅保护同来源的名称检查与文件占位；同名文件/目录递增后缀，实际取流写入继续并行。基础名称、Range 流程、开关及关闭成功才提示规则保持。
- 目录 API/锁不可用时下载资源降级为原另存为，保留原 picker id 和桌面建议位置。规范与功能说明已同步最终两项行为。
