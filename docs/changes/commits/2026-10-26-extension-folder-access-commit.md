# 文件夹遮挡与 EDU 界面锁交付记录

- Issue：[区分文件夹遮挡并为 EDU 添加四位界面锁](../issues/2026-10-26-extension-folder-access-issue.md)
- 状态：已完成
- 预期交付边界：UI 一键淡出遮挡；EDU 以固定 `0000` 四位界面锁解锁；不加密内容、不新增设置。

## 实际交付
- UI 文件夹保持一键显示，改为 EyeOff/Eye；EDU 使用 Lock/LockOpen，在文件夹内部只显示 2×2 密文 Input OTP，输满后自动校验，只有 `0000` 才解除界面锁，错误输入清空。刷新后两者恢复初始状态。
- 按用户最新反馈，UI 与 EDU 均为图标交叉淡变、停留、整个遮罩淡出各 200ms；EDU 四个密码块采用与内部书签相同的 64px 尺寸、16px 间距和四周留白。减少动态效果时直接解锁。锁定期间书签内容不可键盘聚焦，链接处理同时拦截锁定状态；未解锁时点文件夹外部退出并清空输入；解锁完成后焦点留在文件夹容器，不默认聚焦首个书签。
- 接入固定官方来源的共用 Input OTP，四个 Slot 根据用户确认分开并显示密文；`input-otp` 精确固定为 1.5.0，更新 Extension package 与 pnpm 锁文件。只在 Newtab 业务层保留 PIN 和文件夹状态，未添加设置、存储或加密。
- 同步图标映射、现有主题样式、Extension UI 规范和官方 UI 来源记录。

## 验证结果与限制
- 四位码逻辑先观察到失败，再实现通过；布局调整后的 Extension 15 个测试文件、74 项测试、类型检查、生产构建与 diff 检查通过。
- 精确版本依赖安装并同步锁文件；构建保留既有 `theme-init.js` 非 module 提示，本次未改相关入口。
- 未由代理执行浏览器视觉、布局、真实输入、焦点、键盘、动画、减少动态效果和书签导航验收。稳定开发目录未更新。
- 固定 `0000` 仅是界面访问门槛，书签内容没有加密，能够读取扩展源码或存储的人不受保护。
