## 预期交付边界

首页右侧用 Tabs 与 Photos 示意卡片替换大 Logo，支持自动轮换、点击置前与循环补位。保持实际产品功能、下载入口、版本和依赖不变。

## 实际交付

- Tabs 使用现有 SVG 书签网格与有边框的 Dock；Photos 只展示图片、视频、月份、已选数与文字下载。顶部仅保留功能名，两张卡片沿用用户确认的错落堆叠样式。
- 卡片池最多显示三张，每 3 秒循环补位；点击临时置前，不改变池顺序。两张池跳过与当前展示相同的下一窗口，避免首轮等待没有可见变化。正式池仅含 Tabs、Photos，没有临时示例卡。
- 手动与自动切换共用过渡；鼠标悬停、键盘焦点、页面隐藏和减少动态效果偏好暂停自动轮播，离开后重新计时，清理定时器与监听。
- 同步官网说明和视觉规范；Photos 仅为官网展示名，desktop Media 模块不改。
