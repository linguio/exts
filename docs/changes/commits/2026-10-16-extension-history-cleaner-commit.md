## 预期交付边界

独立 history-cleaner 模块及后台入口，Newtab Settings 单开关，默认关闭，本机保存配置；启用后在浏览器配置文件启动和最后窗口关闭时清空访问历史。包含必要权限处理、逻辑与构建验证及说明文档，不扩展到其他浏览数据。

## 实际交付

新增独立 history-cleaner 模块和薄 WXT background 入口，分别监听配置文件启动与最后普通窗口/网页弹窗关闭。默认关闭，本机保存开关；开启时按需申请 browsingData 权限，不立即删除历史，只调用 removeHistory。Settings 复用已有 Button 提供英文单开关与错误反馈，订阅配置/权限变更，后台不依赖 Newtab。同步功能、UI 与 AGENTS 说明，无新依赖或通用原语。

## 未验证事项与限制

关闭触发不保证浏览器退出前完成；启动清理可能包含刚恢复页面产生的新历史，浏览器后台进程持续运行时再开窗口未必触发启动事件。用户反馈功能没有问题，代理未独立实测浏览器，不推断双浏览器逐项验证均完成。browsingData 请求可以直接授予而不弹窗，已同步纠正验收说明。产物为 dist/build/chrome-mv3，未启动 dev server 或刷新稳定开发目录。
