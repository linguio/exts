# 官网视觉规范

状态：已批准，2026-10-11 用户确认尺寸方案；本地实施完成，实际页面效果待用户验收。适用于 apps/website 全部 Web 功能，现有页面包括首页、Changelog 与功能介绍页；本文件维护长期规则，布局交付进度见[对应 Issue](../changes/issues/2026-10-11-website-layout-system-issue.md)，功能介绍页交付进度见[功能介绍 Issue](../changes/issues/2026-10-12-website-feature-overview-issue.md)。

选型与职责遵循根 [AGENTS.md](../../AGENTS.md#web-ui-选型与风格)；官方版本及必要差异见 [Web UI 来源](../web-ui-sources.md)。

采用官方组件基础不重做已确认的视觉：小差异直接沿用官方，明显差异通过主题与组件内必要定制保持现有效果，不在页面各维护一份覆盖样式。

## 主题与组件

- 固定浅色、黑白风格，不增加深色模式。沿用现有系统字体栈。
- 颜色沿用 shadcn 语义 token，定义在 apps/website/src/app/styles.css；业务组件引用语义颜色，不各自新增硬编码颜色。
- 图标入口和年份链接使用现有 shadcn Button，入口说明使用基于 shadcn 官方源码并按主题定制的共用 Tooltip，平台标签使用 Badge，通用图标使用现有 Lucide；品牌资源遵循 [Logo 规范](../exts-logo.md)。
- 仅将各页实际复用的排版与布局值提取为共享规则；不建设额外主题框架，不增加依赖。

## 宽度与间距

- 共用外层最大宽度 1280px，左右内边距手机 24px、640px 起 40px、1024px 起 48px；页头、正文外层与页脚使用同一规则，大屏实际内容最大宽度为 1184px。
- 产品介绍与更新日志使用同一个 SiteDocumentLayout，阅读区域最大宽度 720px；首页上部保留桌面两列和手机上下布局，左侧三层文字与下载组成紧凑整体，与右侧示意区域垂直居中对齐，下部展示四类入口。
- 使用现有 4px 间距步进；常用间距为 8、12、16、24、32、48、64px，保留标签之间 6px 的紧凑间距。
- 日志标题与标签横向间距 12px、换行间距 8px，标题组到正文 16px，列表条目间距 8px；日志记录间距桌面 64px、手机 48px。
- 页面标题到时间线桌面 32px、手机 24px；正文距页头额外留白桌面 48px、手机 32px。
- 标签圆角 6px、左右内边距 8px、上下内边距 2px，保持显示标签的轻量尺寸；导航点击区域 40×40px，保留现有组件反馈。
- 年份分组沿用现有左侧年份、月日、节点与正文列；桌面年份在所属年份组内吸顶，距离固定页头下沿 24px，随年份组结束离开；手机年份放在组上方，不吸顶。

## 共享页头与页脚

- 首页、产品介绍与更新日志复用同一个 SiteLayout；页面最小高度为视口高度，正文弹性填充剩余空间。
- 页头固定于视口顶部：桌面高度 56px、手机 52px；品牌入口使用现有 28px Logo 与 20px Exts 文字，间距 10px。支持 backdrop-filter 时背景使用 background 的 85% 不透明度并模糊 12px；不支持时回退实色 background。仅底部一条 1px border 分割线，无阴影。
- 页脚处于正常文档流中，基础最小高度 48px、上下内边距各 12px，仅显示 Copyright © 2026 Lin Gui，使用实色 background，无模糊、分割线或阴影。
- 短页面由正文弹性填充将页脚撑到屏幕底部，长页面页脚跟在正文后正常滚动；不使用固定页脚或分页面判断长短。
- 正文只预留固定页头的占用；正文末尾保留至少 24px 间距，不再为页脚创建占位。页头和页脚各自保留必要的设备安全区。
- html 统一预留稳定滚动条空间（scrollbar-gutter: stable）；固定页头层级高于正文，不创建嵌套页面滚动容器。

## 定位与交互

- 首页右侧可使用统一窗口框的模块示意卡片：Newtab 图标网格与 Dock、Media 图片／视频网格。示意区域字号按缩略界面的实际比例设置，不套用正文 14px；品牌、边框和颜色仍引用现有语义 token。
- 叠放展示保留原生 button：它承载特殊窗口内容与专用反馈，套用 Button 需要覆盖大部分通用样式，没有实际复用收益。轮换使用现有业务逻辑，不强行换成标准 Carousel。
- 两张卡片采用略倾斜错位叠放，无厚重阴影、底部切换栏或正文模块标题；窗口顶部仅标注 Newtab、Photos，不保留装饰圆点；Newtab 不显示书签文字与文件夹，Dock 图标独立边框，Media 下载为无底色文字，不显示全选。
- 每 3 秒轮换，点击卡片立即开始置前过渡，与自动切换使用相同动画；悬停或键盘焦点进入时暂停，离开后重计周期。页面隐藏时暂停，组件离开时清理定时器与监听；减少动态效果时不自动轮播，手动切换仍可用。鼠标点击留下的焦点不持续暂停，移开鼠标后重新计时。
- 同一展示模块按可用宽度调整图标间距和 Dock 尺寸，避免窄窗口两列布局或手机上的内容截断；以用户实际浏览器验收为准。
- 卡片窗口中的功能名称为 Newtab、Photos，使用 foreground、11px、字重 500；不增加额外标题，实际代码模块命名不因展示名称变化而自动调整。
- 卡片池最多展示连续三张，不足三张不重复补卡。自动轮播按池原始顺序移走窗口首项、向末尾补入下一项，整池循环；点击仅临时置前当前可见卡片，不改变池起点。恢复自动时进入原池的下一窗口，例如 1、2、3 点击 3 后为 3、1、2，下一窗口仍为 2、3、4。测试卡不进入正式数据。
- 点击临时置前后，若自动下一窗口与当前显示顺序完全相同（两张池会出现此情况），跳过这一已展示组合，避免首个 3 秒周期没有可见变化；多张池仍按原序补位。

- 年份链接定位到该年第一条；锚点顶部间距为实际页头占用高度加 24px，包含安全区，避免标题被遮挡。
- 年份颜色加深、字重 500，保留 ghost 按钮的悬停、按下与焦点反馈；不增加自动滚动加载或动画。
- 三页的导航位置一致，图标不使用常驻选中背景，仅悬停时使用 accent 反馈，保留键盘焦点与当前页面的 aria-current 语义。

## 首页工具分类改造设计

状态：用户已批准实施，2026-10-15 已接入本地代码，实际视觉、点击及滚动效果待用户验收。用户确认桌面尽量一屏、小窗口允许滚动、手机不限制滚动，四类入口、单色图标；2026-10-15 本轮按最新批准将左侧文案与下载收为紧凑整体、放大字号，并使用正常文档流中的单行版权页脚。本轮交付进度以[当前 Issue](../changes/issues/2026-10-15-extension-newtab-changes-issue.md)为准，不把构建通过当作视觉验收。

### 首页文字层级

首页介绍包含三层文字，下载按钮独立于文案层级；仅 Title 使用 h1，不把 Title 和 Subtitle 拼成同级两行大标题。

| 层级 | 文案 | 字号：桌面／手机 | 行高 | 字重与颜色 |
| --- | --- | --- | --- | --- |
| Title | Exts | 56px／40px | 1.1 | 600，foreground |
| Subtitle | 将想法与能力延伸为实用工具 | 40–48px／32px | 1.2 | 600，foreground |
| Description | 汇集浏览器扩展、桌面应用、工具包与 AI Skills，让实用能力融入日常与开发。 | 20–24px／16px | 1.625 | 400，muted-foreground |

- 三层按字号、字重和颜色递进，不使用过浅文字或装饰渐变区分。
- Title 到 Subtitle 为 12px，Subtitle 到 Description 为 16px；Description 到下载按钮为 16px。允许正常换行，不截断介绍。
- 首页主展示仍以 Extension、Desktop 为主，保留 macOS、Chrome 下载按钮与固定链接，以及右侧已批准的 Newtab/Photos 展示细节。

### 上部区域与视口适配

- 桌面上部沿用左右两列，左侧是三层文字加下载按钮的整体，右侧是已有叠放示意区域。两侧整体垂直居中，不要求外框或内部元素逐行对齐；768px 起使用两列。
- 左侧文案与下载组成紧凑整体，统一左对齐；下载紧跟介绍，不通过 justify-between 分散到角落。右侧旋转卡片所需的安全留白计入展示区域，不能裁切卡片边缘。
- 主体分为上部展示、下部分类两行，连同固定页头、正常文档流页脚及安全区计算可用空间。不强制一屏；较矮视口、浏览器缩放或文案换行导致空间不足时，页面自然滚动。
- 优先压缩多余上下留白，保留文字可读性、按钮点击区域和展示比例；禁止通过 overflow: hidden、固定高度截断、内容重叠或嵌套滚动强制一屏。
- 首页主体上下留白各 16px，上部展示到分类卡片间距 32px；不缩小字号、按钮、分类卡片内边距或页脚来强制一屏，用户实际视口仍不足时允许自然滚动。
- 手机恢复上下布局，不要求左右同高或一屏，不限制自然滚动。html 保留稳定滚动条空间。

- ≥1024px 时左右两栏间距为 48px，标语不单独限制最大宽度，按左栏可用宽度自然换行；不强制左右同高或改变展示宽高比。展示卡片外框保持 1px，以 foreground 20% 与 background 混色加强轮廓，不添加阴影。

### 下部分类卡片与产品说明

- 分类顺序统一为 Extension、Desktop、Packages、Skills，桌面四列、中等宽度两列、手机一列。产品说明同步四类，删除空的协同分类。
- 每张分类卡片上下内边距各 24px、左右各 20px，不设置固定高度，同一行自然等高；显示 32px 单色分类图标、标题和简短描述，不显示箭头或“更多”，不保留入口占位。整张卡片使用一个链接进入 /features/ 的对应分类；默认预留 1px 透明边框，有 hover 能力时背景加深、边框显现并上移 2px，过渡 150ms；按下回落，键盘聚焦保留 2px 焦点框和 4px 偏移。减少动态效果时禁用位移和过渡；不增加阴影、缩放、Tooltip 或独立控件。
- 分类卡片以文字为主体，不新增大图、动效或依赖。标题 16px／24px、字重 600，正文使用 14px／24px。
- Packages 使用无链接的中文标题“WXT 稳定构建产物工具”，提供一句话用途和 pnpm 安装命令；命令下方并排放“npm 包”“查看源码”，分别指向包主页和源码目录，不添加下载链接或按钮，不固定展示包版本；详细配置留在包 README。官网发布日志使用“发布 <平台或类型> · <模块或功能>”格式：Chrome 为“发布 Chrome 拓展 · 新标签页”，工具包为“发布 NPM 工具包 · WXT 稳定构建产物”，无额外概述，直接列发布改动；日志仅放以包名和发布版本（如 @linguio/wxt-stable-output · 1.0.0）为文字的 npm 链接，指向对应历史版本，不放源码链接；文档修订留在包更新记录。产品说明和日志共用辅助文字链接样式：14px、下划线、hover 加深及清晰键盘焦点，右侧使用 14px Lucide ArrowUpRight，不使用 Button。
- 分类描述表达个人需求：Chrome 拓展集成、macOS 桌面工具、针对开发痛点打造的工具包与脚手架，以及按个人习惯编写改造的 Skills；不把分类限定为现有单一产品。产品介绍标题下放一段精简的个人工具集合概览，更新日志标题下放一句更新与进展说明；两处使用 14px、24px 行高、32px 下间距，不增加概览导航或卡片。
- Skills 当前展示 workflow-change 与 workflow-observer，沿用模块标题、一句话用途和“查看源码”链接，不增加安装按钮或新组件。无条目时产品说明显示“暂无公开 Skills”，分类入口保持可访问，不伪造可用条目。
- 共享页脚只显示单行版权，按正常文档流排列，不遮挡底部卡片；产品说明和更新日志的阅读宽度保持不变。

## 验证与维护

- 功能页沿用 Changelog 的 720px 阅读宽度、页面标题及正文排版；左侧依次为 Quick Start、Extension、Desktop、Packages、Skills，正文继续中文。ghost Button 包装原生 hash 链接，选中项 foreground、其他项 muted-foreground，aria-current 标记当前内容；URL 为内容选择事实来源，刷新、直接打开及前进/后退保留选择，空或无效 hash 回到 Quick Start，快速开始地址为 #quick-start。首页仍只有四类产品入口，原分类 hash 保持有效。

- 必要自动化只检查类型、构建和相关逻辑及产物；视觉、布局、滚动、焦点与点击由用户在 Chrome 或 Edge 验收。
- 规则改变时更新本文件，README、应用约束和 Issue 通过链接引用，不复制整份规则。
- 新页面复用实际需要的规则；超出本规范或当前 Issue 范围的设计变更需另行确认。
