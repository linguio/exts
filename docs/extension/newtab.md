# Newtab 新标签页

Newtab 是 Exts 扩展的新标签页模块，源码位于 apps/extension/src/modules/newtab。加载扩展后，打开新标签页进入书签页面。

## 书签与文件夹

- 页面按文件夹组织网站书签；EDU 文件夹默认带模糊遮罩，锁图标在悬停时变为开锁，点击后显示书签。
- AI 文件夹位于主书签区域第一，依次收录 ChatGPT、Grok、Cursor，使用已有品牌 SVG，打开方式与其他文件夹一致。
- Social Media 文件夹依次收录 Telegram、Bilibili、YouTube；Telegram 打开 Web 版，X 移至 Dock。
- 普通书签提供网站名称和图标，链接打开目标网站；工具分组中的部分入口可批量创建标签组。
- 当前书签来自模块配置，没有可用的用户编辑、拖拽或自定义书签设置。

## Dock

页面保留原有 24px 外圈边距，内部划分为上方左右区域与底部 Dock 行。左右区域边界之间、上方区域底边与 Dock 外框顶边之间均为 24px。

上半区根据容器可用宽度和左侧项目实际宽度自动计算换行，取最宽一行的占用宽度作为左栏宽度，和右栏整体水平居中，将剩余空间平分到两端；不设置固定整体最大宽度或额外空列。ResizeObserver 监听外层可用空间，手动调整浏览器窗口大小时自动更新。左侧末行保持左对齐，不拉伸文件夹；右侧固定为两个文件夹预览外框宽度加一段 24px 间距（默认约 380px），卡片仅纵向排列。左右内容溢出时仅在各自区域内滚动，隐藏滚动条，页面整体不跟随滚动，内容不会侵入 Dock 区域。

首页文件夹的预览框横向相隔 24px；换行后，上下两行预览框之间总共 32px：名称上方 8px、固定单行行高 16px、名称下方到下一行预览框 8px。长名称单行省略，不撑高文件夹行；该规则只作用于首页文件夹。

Dock 按内容宽度在底部居中，最大不超过底部可用宽度；撑满后只在内部横向滚动，隐藏滚动条，保留原有菜单与设置弹层。

底部收藏入口依次为 X、GitHub、Exts、Gmail，直接打开对应网站；ChatGPT 位于 AI 文件夹。Exts 使用已有的完整正式圆角 Logo，保留黑底白色主体，不随页面主题反色。

Components 提供工具菜单；原 DevTools 位置为 Download，点击后打开正文为空的右侧抽屉。Download 与 Settings 抽屉的标题区均为对应图标加标题；入口悬停或键盘聚焦时显示名称提示，抽屉打开时提示收起。

## 右侧卡片

右侧首张卡片为 `Daily check-in`，顶部与首排文件夹预览外框对齐，高度等于文件夹预览外框（默认约 178px，不含名称），宽度占满右侧列。首行右侧使用 Settings 同款 ToggleGroup，只有固定选中的 `JLPT` 项；不提供 GitHub 入口、计时或编辑功能。

日历按本地日期显示当前周和之前 23 周，每列为周日到周六，最右列是当前周。每格 12px、间距 2px，24×7 格区域为 334×96px，水平居中。未来日期留空，缺失日期按 0 分钟展示；跨本地午夜或切回标签页时重新计算日期。

数据独立保存在 `apps/extension/src/modules/newtab/views/cards/check-in/data/jlpt.json`，日期键为 `YYYY-MM-DD`，值为当天累计整数分钟数。本次提供 2026-09-23 至 2026-10-22 共 30 天模拟记录，只含 0、30、60、90，不代表真实学习数据，运行时不会重新随机。需要更换记录时编辑该 JSON 并重新构建。

四档灰度分别对应 0、1–30、31–60、>60 分钟，随明暗主题切换。只有正分钟数格子显示共用 Tooltip：首行为 `10-22 · 星期四`，第二行为 `学习时长：30分钟`、`学习时长：1小时` 或 `学习时长：1小时30分钟`；0 分钟与未来日期没有 Tooltip。

`views/cards/index.tsx` 组合右侧卡片；首张卡片由 `views/cards/check-in/` 独立目录持有，其中入口组合标题与日历，`calendar-grid.tsx` 展示格子和 Tooltip，`calendar.ts` 处理本地日期、等级与文案，`use-local-date.ts` 维护当前本地日期，`data/` 保存 JSON。其他卡片后续各用独立目录，不将业务堆入页面入口。`views/bookmarks/` 负责左侧书签，`views/dock/` 负责 Dock、工具菜单及设置入口，`views/settings/` 保留通用设置视图。

## Settings

Dock 右侧的 Settings 打开右侧设置面板，面板跟随当前明暗主题，分为两区。Download 与 Settings 的入口提示及抽屉关闭焦点处理共用 Dock 局部 hook：

General 与 Features 之间不使用分割线：分区标题为 12px、中等字重和较淡颜色，设置项正文为 14px、常规字重；正文外侧内边距和两区间距统一为 24px，不再叠加子分区内边距。顶部 Settings 标题区保留分割线。

- General：Theme 提供太阳、月亮、笔记本（LaptopMinimal）三个图标，对应 Light、Dark、System。默认 System，手动选择立即应用并保存在本机，多个已打开页面同步；System 随系统变化，手动 Light/Dark 保持固定。
- Features：Clear History 默认关闭，旁边问号通过 Tooltip 展示原清理范围与触发说明；错误直接显示在区域内。

[历史清理](./history-cleaner.md)模块独立持有配置与后台行为；Newtab 只展示设置区域，不需要保持页面打开。启用时申请浏览器清理权限，拒绝则保持关闭；开启操作本身不立即清理。

## 使用与限制

- 面向 Chrome、Edge，不要求其他浏览器兼容。
- 未配置主题时跟随系统或浏览器的配色偏好；手动选择后按所选主题显示，单色书签同步适配，品牌原色保持不变。首次加载、跨页与系统切换的实际效果由用户验收。
- 开发时加载根 dist/dev/chrome-mv3-dev-stable，生产构建加载 dist/build/chrome-mv3；具体操作见[应用 README](../../apps/extension/README.md)。
- 本模块不要求其他扩展功能依赖 Newtab 页面保持打开。

共用样式和组件规则见[界面规范](./ui.md)，构建产物规则见[构建与分发](../build-release.md)。
