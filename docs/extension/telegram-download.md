# Telegram Download

Telegram Web 图片、视频右键下载，模块位于 apps/extension/src/modules/tg-download/。在 Telegram 页面取流并流式写入用户选择的文件夹，不连接 Desktop，不额外登录。

## 模块与配置

- components/download-menu：复用官方 DropdownMenuItem asChild 与 Button ghost，菜单只有“下载资源”和“选择文件夹”，无常驻目录或帮助说明；必要错误时显示恢复文字。
- download-core：媒体保存、Range 写入、文件名、目录目标与 IndexedDB 句柄存储。平台下载逻辑与文件选择都留在 TG 模块。
- page：媒体识别、页面注册、开关/主题接入；没有下载记录或后台任务上报。
- views/settings 与 settings.ts：默认开启，配置保存在 storage.local。关闭立即阻止新下载，正在写入的任务继续；Newtab 只组合功能开关。

仅注入 https://web.telegram.org/*，保留 Telegram Web K 的 .media-viewer-mover 识别边界。开关与主题由隔离环境发布，扩展重载后旧页面入口停用，刷新恢复；不承诺关闭 Telegram 页面后下载继续。

## 快速保存与选择文件夹

- 下载资源：首次未配置目录时，在点击栈内打开系统目录选择器，选好并记住后立即保存当前媒体；已有选择时直接保存到该文件夹。取消首次选择不请求媒体、不提示成功。
- 选择文件夹：选择或更换后续保存位置，仅记住文件夹，不立即下载；取消或持久化失败保留原选择。
- 不限制名称，不创建 Exts、Telegram 或其他固定子目录。旧版句柄直接作为当前保存目录，不迁移、删除或整理历史文件；若希望继续保存在原子目录，可通过“选择文件夹”选中该子目录。
- 目录选择器建议从 downloads 打开，浏览器可记住上次位置。整个 Downloads、用户根目录等可能被浏览器拒绝授权，用户可以选择普通子目录；这与文件夹名称无关，程序不绕过浏览器限制。
- 目录句柄位于 Telegram 同来源专用 IndexedDB（exts-telegram-download / directory / selected），页面启动时恢复到内存，不放入 chrome.storage.local。首次读取完成前两个操作暂不可用。每次下载在点击栈内请求写权限，持久化不保证永久授权。
- 清除站点数据会移除记住的目录。多个 Telegram 页面各自缓存选择，其他页面刷新后读取最后保存的选择。文件夹删除或权限失效时通过错误文字恢复，不自动重试或切换到其他目录。
- 同名文件/目录采用“文件名 (1).扩展名”递增避重。Web Locks 只保护同来源页面的名称检查与文件占位，实际下载流并行；不保证与外部应用同时创建文件的原子避重。失败可能留下空占位文件，不删除用户文件。
- 浏览器不支持目录选择 API 或锁时，“下载资源”降级为系统另存为，保留原 picker id、桌面建议位置及基础文件名；菜单不提供独立另存为项。

## 写入与完成提示

图片/视频按响应流写入，分段响应继续 Range 请求。只有 writable.close() 成功后显示“下载完成”与实际文件名；开始、进度、失败、取消不弹 Toast。失败时中止写入并记录日志，目录错误只通过菜单提供恢复说明。

完成提示复用 shared/ui/sonner，多个提示沿用官方折叠行为，不维护全局通知或下载记录层。Popup、公共 downloads 与历史消息不在当前功能范围，不清理旧记录存储。

## 用户验收

1. Chrome/Edge 重新加载根 dist/build/chrome-mv3，刷新 Telegram Web K，在媒体查看器右键，检查菜单仅有下载资源、选择文件夹，无常驻提示。
2. 若尚未选择目录，点击下载资源，选一个浏览器允许的普通文件夹，确认当前媒体立即保存到里面，不额外创建子目录；之后连续下载不再选择位置。已有旧选择时先检查文件直接保存到旧句柄对应目录，再通过第二项更换。
3. 点击选择文件夹，换成任意其他名称的普通文件夹，确认该操作不下载，之后下载资源保存到新位置。取消更换后仍使用原位置。
4. 刷新后确认记住目录；重启或撤销站点权限后验证重新授权。删除目录或模拟磁盘失败应提供恢复提示，不误报完成；浏览器拒绝整个 Downloads 时改选其中普通子目录。
5. 验证同名文件/目录递增避重，两个 Telegram 页面并发保存互不覆盖，完成后文件内容可打开；首次选择取消不下载。
6. 检查主题、菜单、完成 Toast、功能开关和扩展重载等既有边界。只有文件关闭成功后显示实际文件名；旧脚本在扩展重载后停用，刷新恢复。

代理仅验证纯逻辑、类型和构建；系统授权、真实 IndexedDB 克隆/恢复、浏览器重启、磁盘内容及菜单交互由用户验收。用户此前确认整个 Downloads 授权被浏览器拒绝，此限制不因简化菜单而消失。
