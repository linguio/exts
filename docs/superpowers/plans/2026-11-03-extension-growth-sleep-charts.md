# 成长与睡眠模拟图表实施计划

> 执行：使用 superpowers:executing-plans 串行实施；禁止子代理，不自动提交。

**目标：** 在现有 ActivityCard 中展示已批准的日历、成长/睡眠趋势和周投入/计划。
**架构：** Studio 持有固定 JSON、类型、纯日期/聚合工具与业务图表；shared/ui 持有固定官方 Chart 源码。按用户最新批准，全局 --chart-1 至 4 持有中性灰，日历只作别名映射；Token 参数与背景/相邻对比核算统一记入应用 UI 规范。
**技术：** React、TypeScript、shadcn/ui、精确版本 Recharts；沿用现有 Vitest 纯逻辑环境。
**依据：** [Issue](../../changes/issues/2026-11-03-extension-growth-sleep-charts-issue.md)，用户已明确批准的讨论与开始指令。

## 重点验证与停止点
- 缺失睡眠不计 0，合法低于 30 分钟成长时长仍参与聚合；日历只计算达标项数。
- 周日到周六的本地日期范围；未来记录不参与当前统计。
- 进度环使用独立 0–100 域，防止按最大项目自动缩放；超额仅截断图形、不截断提示值。
- 固定数据不随机；无动态时间平移，样本日期之外自然呈现空状态。
- 禁止浏览器/像素/布局/交互测试；视觉与交互由用户实际加载验收。
