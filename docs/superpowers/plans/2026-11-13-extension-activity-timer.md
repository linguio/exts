# 活动翻页倒计时实施计划

**目标：** 实现已批准的日历上方倒计时卡片。
**依据：** [Issue](../../changes/issues/2026-11-13-extension-activity-timer-issue.md)；聊天中布局与行为已确认。
**实施：** 串行执行，不启动子代理；完成后停在用户验收，不提交。

## 步骤
- [x] 核对官方 Base Slider 的源码、主题样式与固定版本，安装精确依赖；记录来源及差异。
- [x] 先验证计时计算/重设/归零等纯逻辑，再实现 use-countdown.ts；状态留在卡片内存，调度不依赖会随 React Activity 隐藏而断开的 Effect。
- [x] audio.ts 负责音频合成与释放，completion.ts只负责一次性Toast，不请求系统通知权限；关闭页面停止，不使用后台持续任务。
- [x] timer-card.tsx 与翻页数字保留原 Demo 已认可的两阶段顺序，布局复用现有卡片及主题；NewtabCards 仅组合。
- [x] 验证纯逻辑、类型和构建；依赖变化按仓库要求运行扩展测试，禁止新增视觉/焦点/指针测试。
- [x] 同步交付结果、布局计算与未验证项，交付 Chrome/Edge 用户验收。

## 边界与停止点
- 用户后续取消系统通知；仅Toast和合成结束音，休眠/冻结可能延后提示，不承诺系统级闹钟。
- 不修改既有日历请求、不新增音效下载、不替换扩展主题、不扩展为通用计时框架。
- 依赖无法安装或指定官方组件无法满足时说明具体阻塞，不自行换组件。

- [x] 用户补充批准后增加Clock/Timer图标双向切换，本地HH:mm分钟变化翻页；移除右侧分钟数和通知权限，复用原倒计时翻页。

- [x] 用户补充批准后接入官方Base右键菜单、两组英文七种声音、本地偏好与排他试听；选项按短到长排列，保留截止时间，不扩展全局Toast声音。
- [x] 用户明确要求另建“完善Toast的提示音”排队Issue及对应Commit记录，仅建档、不实施。
