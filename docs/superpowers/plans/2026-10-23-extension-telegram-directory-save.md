# TG 快速保存与文件夹选择实施计划

> 按 executing-plans 在当前 checkout 串行实施；不使用子代理，不提交。

**目标：** 首次选好目录后立即下载，后续快速保存，并可单独更换文件夹。
**设计依据：** [Issue](../../changes/issues/2026-10-23-extension-telegram-directory-save-issue.md) 的最终设计，以 2026-10-24 用户最新要求为准。
**技术：** 现有 React / shadcn DropdownMenu、File System Access、IndexedDB、Web Locks，无新依赖。

## 边界

- TG MAIN world 取流和写入；目录句柄在 Telegram 同来源，Newtab 不介入。
- 任意浏览器允许的文件夹，不限制名称，不创建固定子目录，不迁移历史文件。
- 菜单只保留下载资源、选择文件夹，无常驻提示；只有错误恢复文字和成功完成 Toast。
- 下载资源首次直接调用目录 picker，选择并持久化后继续保存；第二项只更换选择，不下载。
- 取消或存储失败保留原选择；权限检查在点击栈内发起。目录 API 不可用时降级原另存为。
- 基础文件名、开关、Range 流写入保持；同名递增避重，锁仅保护名称分配。

## 验证与停止点

重点：任意名称恢复、首次选择后保存、取消不创建文件、更换失败保留原目录、权限拒绝不取流、同名并发不覆盖。
完整验证：扩展 test --maxWorkers=1 --no-file-parallelism、typecheck、pnpm ext:build、git diff --check。
不测试菜单视觉/焦点/指针，不启动浏览器或开发服务器；产物为 dist/build/chrome-mv3，结束后停在用户验收。
