# 业务查询表格复用实施计划

依据：[设计](../specs/2026-11-09-extension-data-table-reuse-design.md)与[Issue](../../changes/issues/2026-11-09-extension-data-table-reuse-issue.md)。用户已于 2026-11-09 批准开始实施，仅查询复用。

## 约束
- 复用现有 DataTable 和官方控件；不新增依赖、后端接口或 CRUD。
- 串行执行，不使用子代理、假 DOM、布局或指针交互测试，不自动提交。
- 保留现有直接使用 DataTable 的方式；Daily 使用统一查询入口。

## 实施顺序
- [x] 在现有 types/state 中增加查询配置、请求/结果类型及纯状态转换，覆盖草稿、生效条件、默认值、Reset 和分页排序转换。
- [x] 增加内部请求执行函数及 useDataTableQuery，纯异步覆盖取消/迟到/异常及元数据边界；未知异常使用通用提示。
- [x] 增加 QueryDataTable，scopeKey 隔离状态，原 Toolbar 补受控查询模式并保持即时模式兼容。
- [x] Daily 迁入配置入口，删除旧查询状态、Effect 和手写工具栏；安全请求与校验保留。
- [x] 扩展完整 140 项测试、类型检查及本地 API 构建通过，文档同步，用户已验收通过。

## 停止点
实现与自动化完成后停在用户验收，提供产物路径、Daily 操作步骤及精简后的调用代码；未实际验证的浏览器/真实接口行为如实记录。

用户于 2026-11-09 验收通过并明确批准 commit，代码与文档两笔本地提交完结；未推送或部署。
