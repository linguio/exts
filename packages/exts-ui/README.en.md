# @linguio/exts-ui

[中文](./README.md) · [Source](https://github.com/linguio/exts/tree/main/packages/exts-ui) · [npm](https://www.npmjs.com/package/@linguio/exts-ui)

A React component library based on shadcn/ui, offering consistent foundations and reusable enhancements for applications.

## Features

- Retains shadcn/ui foundation component names and design conventions.
- Provides foundations through `ui` and composes reusable enhancements through `plus`.
- Includes type declarations and compiled styles for application integration.

## Requirements

React and React DOM **19.3.0**, and a React project supporting ESM and CSS imports.

## Installation

```sh
npm install --save-exact @linguio/exts-ui@0.2.0
```
