# @linguio/exts-ui

[English](./README.en.md) · [源码](https://github.com/linguio/exts/tree/main/packages/exts-ui) · [npm](https://www.npmjs.com/package/@linguio/exts-ui)

基于 shadcn/ui 的 React 组件库，为应用提供风格一致的基础组件与可复用的增强能力。

## 主要能力

- 沿用 shadcn/ui 的基础组件名称与设计风格。
- 以 `ui` 提供基础组件，以 `plus` 组合通用增强能力。
- 提供类型声明与预编译样式，便于接入应用。

## 使用要求

React 与 React DOM **19.3.0**，以及支持 ESM 和 CSS 导入的 React 项目。

## 安装

```sh
npm install --save-exact @linguio/exts-ui@0.2.0
```
