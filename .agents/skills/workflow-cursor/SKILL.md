# Cursor 串行委派

Codex 明确任务与验收、向 Cursor CLI 交接并审查交付；Cursor 执行批准范围内的工作。复用当前仓库的 Issue、验证及提交规则，不建立另一套流程。

## 授权与模型

- 仓库规范已将 Cursor 设为默认实施者时，开发范围获用户批准后自动使用本 Skill，无需每次再次请求委派授权；其他仓库仅在用户明确要求 Cursor 或显式调用本 Skill 时使用。规划和调用 Skill 本身不批准尚未明确的实施或外部操作。
- 遵守用户与适用 AGENTS 的最新约束。存在委派禁令且用户本次未明确授权例外时，说明冲突并停止委派；Skill 本身不能覆盖仓库规范。
- 默认固定模型 `composer-2.5`，不启用 Auto 或 Fast；用户指定的模型和档位优先。不可用时说明事实，等待用户选择，不静默换模型。
- 开始实施时向用户说明正在使用 workflow-cursor、Codex 负责规划与审查、Cursor 负责实施以及本次模型。调用受阻时说明原因，不静默由 Codex 接管；用户明确改由 Codex 执行时遵从。
- Codex 可按授权维护流程与交付文档、执行本地提交；业务实现和审查后的代码返工仍交给 Cursor。用户负责的最终验收不由任何 Agent 代替。
- 本 Skill 不决定 Codex 自身模型，不承诺某模型的能力排名、价格或账号可用性。

## 调用前

1. 明确本次是只读咨询还是已批准的实施，读取当前工作项与实际需要的约束。实施沿用当前 Issue，不为一次委派另建 Issue。
2. 串行记录当前目录、分支、Git 状态与相关既有 diff；区分已有修改，禁止清空、覆盖或认领其他工作。
3. 通过命令发现或已确认的绝对路径定位 Cursor CLI，核对版本、`--help`、登录状态与所选模型；已有有效结果可复用。不把编辑器的 `cursor` 命令或安装成功当作 Agent 连通证据。
4. 缺少 CLI、登录或模型时只说明具体阻塞；安装、更新、登录、环境配置和额外权限按用户授权处理，不把授权写入提示词冒充工具权限。

## 交接任务

给 Cursor 一份简短、完整的任务说明，包含：

- 用户目标、批准范围、当前 Issue 和必须读取的规范路径。
- 正确工作目录、允许修改的区域、已有修改及必须保留的行为。
- 明确排除项，以及确有必要的实施约束；不要逐行规定实现。
- 约定检查、用户可观察的验收标准和停止点；用户负责的浏览器视觉与交互验收不得代做。
- 输出要求：实际修改文件、完成内容、检查命令与结果、未完成项和限制。

不得传入凭据、认证文件内容或无关的完整聊天历史。禁止 Cursor 自行提交、暂存、推送、发布、扩大范围、安装依赖、启动其他代理或更改全局配置；确属用户批准的任务内容时，仅开放相应具体动作。

## 执行与返工

- 使用 CLI 的非交互 `--print`、固定 `--model` 和合适的输出格式。只读咨询必须使用 `--mode ask`；`--print` 本身不是只读保证。
- 使用参数数组传递提示词，避免 Shell 拼接或插值执行。提示词过长时按 CLI 实际支持的接口处理，不猜测标准输入或参数。
- 不默认使用 `--force`、`--yolo`、`--approve-mcps` 或关闭沙箱。工作区信任须核对确切目录，不能替代单项权限批准；遇到权限请求或授权不足时按环境规则处理。
- 同一时间只运行一个执行者；Cursor 工作时 Codex 不同时修改工作区或运行竞争检查。不得再委派、并行启动其他 Agent 或后台任务。
- 保存本次返回的会话 ID，返工只恢复这一会话；共享环境中不使用可能续接其他任务的“最近会话”。不依赖 Cursor 编辑器已有对话，也不假设能自动共享 Codex 上下文。
- 长任务保持进度沟通，按仓库超时和资源规则处理。中断后先确认进程状态，再继续，不另起第二个执行者；停止会话不自动回滚其修改。
- 同一失败最多一次原因定位与一次修复重试；再次相同失败时停止，报告已确认事实、实际影响和可选路径。范围变化、权限不足、模型不可用、额度不足或账号问题也需先说明，不循环重试。

## 审查与交付

1. Cursor 结束后核对进程结果、Git 状态和实际 diff，包含未跟踪文件；不能仅凭退出码为零或自述完成认定成功。
2. 审查范围、核心行为、已有修改保护及明显缺陷。发现越界先停止并说明，不用 reset、clean 或覆盖文件自动撤销不明归属的修改。
3. 核对检查命令、输出与最终代码是否对应。证据有效则复用；只补确有缺口或输入已变化的必要检查，不机械重复全量验证。
4. 向用户报告实际交付、验证结果、限制和验收步骤，按当前 Issue 规定的停止点收尾。用户未批准提交时保持未提交；用户只要求本地提交时不重新启动 Cursor 或追加验证。

## 最小调用示例

仅在已确认 CLI 支持这些参数、已登录且工作目录正确时使用：

```powershell
$cursorArgs = @('--mode', 'ask', '--model', 'composer-2.5', '--print', '--output-format', 'text', '只读检查指定问题，说明结论依据；不要修改文件或执行有副作用的操作。')
& $cursorCli @cursorArgs
```

`$cursorCli` 来自命令发现或已核实的路径；实施时移除只读模式，替换为批准的完整任务说明。示例不自动批准任何执行。
